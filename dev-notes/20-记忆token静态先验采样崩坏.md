# 显式记忆 token（静态前缀版）：val 历史最佳但采样崩坏

## 背景（为什么做）

拓扑实验 B 系列（dev-notes/18/19）关闭"删注意力"方向后，指认病根为**长期信息检索通道缺失**：
注意力窗口（256 token）+ Sinks 隐性锚点训满失效 → 模型采样时找不到跨轮次长程信息。本次试"显式记忆 token"：
序列前插入 K 个可学习嵌入，参与每一层注意力+FFN，作为强制参与所有层的全局工作区。

## 改动（Python-only）

- `model/model.py`：`GPTConfig` 加 `n_memory_tokens: int = 0`；`CausalSelfAttention` 的 RoPE cos/sin 表和
  非 flash 因果掩码扩到 `block_size + n_memory_tokens`（K=0 时形状不变 → 老 checkpoint 兼容不破）；
  GPT 加 `memory_tokens` 参数（K×n_embd），forward 里拼到序列前、过完所有层后剥离（不喂 lm_head/MTP）。
- K=16 = `csa_compress` 整数倍 → 记忆块与压缩块边界对齐，真实 token 的块划分零偏移。
- 参数量 +16×80=1,280（0.04%），全部参与训练 → 规模匹配，纯拓扑变量。
- 配置 `train_chinese_mem.yaml`；采样器 `sample_py.py` 无需改（memory 在 forward 内部拼/剥）。

## 验证（已跑）

- 参数量：基线 2,849,036 vs mem 2,850,316（+1,280 ✓）；forward/backward 正常（256+16=272 超 block_size 仍过）、
  memory_tokens 梯度非零（真正参与训练）、generate 形状正确。
- 老 checkpoint 兼容：af best.pt 用 train.py 同款逻辑（剥 `_orig_mod.` + n_memory_tokens 兜底 0）加载 OK。
- `smoke_test.py` 通过（新增 `记忆token` / `记忆token+mHC` 用例）。

前期略慢（250-500 落后），1250 打平，1500 大幅领先。train loss 3.818 < af 4.083 同样更低。

## 但采样崩坏（判据为准）

3 个 prompt × 目测，mem 全部崩成**文字拼贴**：古文对话片段（"苏鲁克道"）、物件清单（"白鹦鹉/花鸟/毛头头肉虫子"）、
emoji（👏😱）、拟声词（"唃,和牛声"）、音乐平台热评——**对话框架完全丢失**。af 虽绕圈但保持中文连贯和对话结构。
多轮记忆测试（prompt 埋"小明/水彩"）：af 主题连贯，mem 完全无视上下文、不引用任何前置信息。

**因果诊断（清零干预）**：把 memory_tokens 清零后重采样，质量大幅恢复——主题连贯、对话框架在、af 级水平。
→ 记忆 token 是采样崩坏的直接原因，不是 1500 步欠训练的问题。

## 根因：静态先验 → 生成被先验支配

静态 memory token 是"训练期学会写入"的**数据集级压缩先验**，不是"可按输入写入"的工作记忆：

- 训练/验证时：16 个向量吸收数据集级统计（val 同分布），教师强迫下拟合更好 → **val 降 0.15 是捷径收益，不是智能增益**。
- 自由生成时：没有真实输入可写进记忆（向量是固定的），模型只能"复读"先验里编码的文字拼贴，
  而不依据输入上下文 → 崩坏。
- 清零后：模型被迫依赖真实上下文，反而恢复连贯 → 证明先验支配是根因。

## 怎么避免 / 方向再校准

- **与 dev-notes/14 同构**：Sinks 是隐性锚点、memory tokens 是静态先验——**训满后都被模型利用成捷径**
  （Sinks→死循环，memory→文字拼贴）。显式/隐式的"固定锚点"这条思路在小模型上是伪胜利。
- **判据强化**：低 val + 采样崩坏 = 模型在利用捷径，不是学到更聪明的表示。**若只看 val，memory token 会是一个伪胜利**——
  再次证明"以智能为目标、loss 只是必要条件、采样目测为准"（与评估标准一致）。
- 静态前缀 memory token **关掉**（默认 0，不进默认配置）。若真做"工作记忆"，需要**输入条件化的读写机制**
  （按输入把信息写进槽、再跨 token 读），实现成本高一个量级，暂不优先。
- 拓扑搜索目前全部负结果（块内重排、删注意力×2、静态记忆），"全注意力 + attn_ffn + Sinks"仍是最优布线。
  下一轮值得赌的转向**训练/数据维度**或**输入条件化记忆**，而非再改静态结构。
