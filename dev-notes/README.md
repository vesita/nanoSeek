## 核心事实速查（不用翻笔记）

```
重复坍缩病根   = 欠训练 → 押高频 token / 重复上一个 token（06）；训满分布尖锐 → 全角空格坍缩（14）
Sinks          = 打破重复的必要条件（11），但训满必失效（14）——已在默认配置
repeat-penalty = 解码端治标，1.1~1.3 常用（16）；RL 不是现在
LSE 残差       = 抗重复机制成立（rep3 1/3.6）但硬替换拖垮学力（23）；gate-mix 可学习 α 是甜点（24）
QK+Z-Loss      = 近零参数稳定性：合开 val 1.002→0.813 超线性（25），建议进默认
mHC            = 收敛加速 -0.34（13），进默认；Indexer/Hash 关闭
拓扑搜索       = 块内重排/删注意力/静态记忆全负结果（17/18/19/20）——别再试"删/换已有通道"
模型规模       = 词表×维度占大头（05：8k 词表 35% vs 30k 67%）；8000 词表 + 6×80
数据治理       = zhuangxialie 占 55% 是碎片拼贴根源（21）；--task-ratio 剔除后 train 30M token
```
