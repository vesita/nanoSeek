## 核心事实速查（不用翻笔记）

```
重复坍缩病根   = 欠训练 → 押高频 token / 重复上一个 token（06）；训满分布尖锐 → 全角空格坍缩（14）
Sinks          = 打破重复的必要条件（11），但训满必失效（14）——已在默认配置
repeat-penalty = 解码端治标，1.1~1.3 常用（16）；RL 不是现在
LSE 残差       = 抗重复机制成立（rep3 1/3.6）但硬替换拖垮学力（23）；gate-mix 可学习 α 是甜点（24）
QK+Z-Loss      = 近零参数稳定性：合开 val 1.002→0.813 超线性（25），已进默认
mHC            = 收敛加速 -0.34（13），进默认；Indexer/Hash 关闭
拓扑搜索       = 块内重排/删注意力/静态记忆全负结果（17/18/19/20）——别再试"删/换已有通道"
模型规模       = 词表×维度占大头（05：8k 词表 35% vs 30k 67%）；8000 词表 + 6×80
数据治理       = zhuangxialie 占 55% 是碎片拼贴根源（21）；--task-ratio 剔除/0.25 重平衡（27）
1500 步护栏    = 训满（5000 步）必重复坍缩（30 验证 14）；1500 步上限是防坍缩的质量保护，数据扩充也救不了
数据构成       = 比例不是性格瓶颈（29：情感支持砍到 7% 仍是话术碎片）；真正出路 = 真实闲聊语料
```

## KV 记忆设计（数据支撑，来自 31/33）

```
KV 有效秩   = K ~8/20、V ~5/20（QK-Norm 下 K 范数恒 1）→ 记忆 latent l=8~16 足够
长程需求    = 块路径 42% 质量在窗外、p95 到达 ~220 token → 全局记忆是刚需
HCA 槽位    = glob 贡献（0.09-0.14）是三条路径里最弱 → 可学习记忆替换 HCA 的最优位置
距离不敏感  = 滑窗内注意力近均匀（δ=0 0.050 约 3×均匀，其余 0.009-0.026）→ 固定窗 64 边界可疑
sink 预算   = 每头 ~10% 质量进 sink → 记忆路径也保留持久/垃圾桶槽位
掩码修复收益 = best val 8.2842 vs 8.3198（修复前，synth@300）——修复正确且更好
```
