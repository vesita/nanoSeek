# 39-记忆路径优化清单与实施（低显存模式先行）

## 数学核心观察（推导）
记忆路径写入是 rank-1 外积 `k·vᵀ` 的累积：
`S_t = r⊙S_{t−1} + β·k_t v_tᵀ`
→ **S 的有效秩 ≤ min(键的秩, 值的秩)**。
观测台实测 K 有效秩 ~8/20、V ~5/20 → 16×16 黑板里一半以上维度数学冗余。

## 候选清单（按置信度排序）
| # | 优化 | 依据 | 代价 |
|---|---|---|---|
| 1 | latent 16→8 或显式低秩分解 S=L·Rᵀ | 秩被写入秩锁死（推导） | 低，A/B 训练 |
| 2 | Delta 擦写律（P2） | 叠加式写入在键冲突时混叠；`S←S+β(v−Sk)kᵀ` 先擦后写 | 高（DeltaNet chunkwise） |
| 3 | r/β 双门合一 | 遗忘与写入由同一输入决定，层均值正相关 | 低，A/B |
| 4 | **D 矩阵 rank-1 可分离（本文件实施）** | D[i,j,h,l]=exp(G_i)·exp(−G_j) 逐通道 rank-1 | 中（等价重写） |
| 5 | 持久记忆=初始黑板 S₀=P | P 等价于 r 永不衰减的通道 | 很低（概念化简） |
| 6 | mHC 4 流→2 流 | 核心信息在 B（双重随机），A/C 是平均+缩放 | 中 |

## 本次实施：#4 低显存模式（D 矩阵消掉）

### 推导
当前块内检索：
```
inner[i,h,l] = Σ_{j≤i} exp(G_i−G_j)·scores[i,j]·ck[j,l]     （D 矩阵显式物化 (B,C,C,nh,l)）
```
D 逐通道 rank-1 可分离：exp(G_i−G_j) = exp(G_i)·exp(−G_j)。
直接写 exp(−G) 会溢出（G 深负 → exp(300)=inf → inf×0=NaN，历史教训"先掩码再 exp"）。

**数值安全重写（max-subtraction）**：m = 块内 min(G)（逐 b,h,l），G̃ = G−m ∈ [0, range]：
```
exp(G_i−G_j) = exp(G_i−m)·exp(−G̃_j)
inner = exp(G̃) ⊙ einsum('bjhl,bihj->bihl', E, scores_m)    E=exp(−G̃)⊙ck，scores_m=因果掩码后
cum   = exp(G̃_last) ⊙ einsum('bjhl,bjhm->bhlm', E, vc)      A_out 更新同法
```
所有因子有界：exp(G̃)∈[e^{−range},1]、exp(−G̃)∈[e^{−range},1] → 无溢出、无 NaN。
内存：块内 (B,C,C,nh,l) D/diff 消失 → 峰值降 ~20 倍（C=64@batch64：1.6GB → ~80MB）。
代价：scores 需显式因果掩码（原来由 D 的 −inf 提供）。

### 验证
- 等价性：同权重同输入，新实现 vs 旧实现输出相对差应 ~1e-6（浮点求和顺序差异）
- smoke_test 通过；C=64@batch64 恢复不 OOM

### #4 ✅ 低显存（梯度检查点版，非 rank-1 分解）
- **数学修正**：rank-1 分解 exp(G_i−G_j)=exp(G_i)·exp(−G_j) 在 fp32 下必然中间爆炸
  （G 深负时 exp(−G_j) 单独溢出 → inf×0=NaN，即"先掩码再 exp"教训的翻版）。
  正确落地：**梯度检查点**（backward 重算块内 D）——数学完全等价（同一函数体），
  省去逐 chunk 保存 D（总量 B·T·C·nh·l，C=64@batch64 全模型 1.6GB）。
- 实现：chunk 循环体提为 `_mem_chunk_step` 静态方法；`kv_memory_checkpoint` 开关入 config。
- 验证：checkpoint vs 内联 **forward/backward/全部参数梯度 max|Δ|=0**（bit 级等价）；
  C=64+checkpoint+compile @batch64 **1.27 it/s 不 OOM**（与 C=32 同速，recompute 被大 chunk 抵消）。
