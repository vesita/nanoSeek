# 39-记忆路径优化清单与实施（低显存模式先行）

## 数学
写入 = rank-1 外积累积 `S_t = r⊙S_{t−1} + β·k_t v_tᵀ` → **S 有效秩 ≤ min(键秩, 值秩)**；实测 K 秩 ~8/20、V ~5/20 → 16×16 黑板一半以上维度冗余。

## 候选清单（按置信度）
1. latent 16→8 / 低秩分解 S=L·Rᵀ — 秩被写入秩锁死；低代价 A/B
2. Delta 擦写律（P2）`S←S+β(v−Sk)kᵀ` 先擦后写，治键冲突混叠；高代价（DeltaNet chunkwise）
3. r/β 双门合一 — 遗忘/写入同源、层均值正相关；低代价 A/B
4. **D 矩阵 rank-1 可分离（本次实施）** — D[i,j,h,l]=exp(G_i)·exp(−G_j)；中代价等价重写
5. 持久记忆 = S₀=P — 等价 r 永不衰减的通道；极低代价
6. mHC 4 流→2 流 — 核心信息在 B（双重随机），A/C 仅平均+缩放；中代价

## 实施 #4：低显存（梯度检查点版）
- **数学修正**：rank-1 分解 exp(G_i−G_j)=exp(G_i)·exp(−G_j) 在 fp32 下必然中间爆炸（G 深负 → exp(−G_j) 溢出 → inf×0=NaN，同"先掩码再 exp"教训）；曾试 max-subtraction 后放弃。
- 落地：**梯度检查点**（backward 重算块内 D），数学等价，省去逐 chunk 保存 D（总量 B·T·C·nh·l，C=64@batch64 全模型 1.6GB）；chunk 循环体提为 `_mem_chunk_step`，`kv_memory_checkpoint` 开关入 config。
- 验证：checkpoint vs 内联 forward/backward/全部参数梯度 **max|Δ|=0**（bit 级等价）；C=64+checkpoint+compile @batch64 **1.27 it/s 不 OOM**（与 C=32 同速）。

### #1 ✅ latent 16→8（300 步 A/B，2026-08-30）
- latent 8 best val **5.3707** vs latent 16 **5.3607**（差 +0.010，噪声级）→ **latent 8 ≈ latent 16**，验证"黑板秩被写入秩锁死"（K 秩 ~8 恰为 latent 8）；记忆通道参数减半，阶段性训练可用 latent 8。
- 用户确立训练预算：一般测试 300 步、阶段性测试 1500 步。

## 决策
先 #4（零风险工程）→ #1（latent 8 A/B）→ #3 → #2（最重，最后）；#4 落地后记忆训练恢复 C=64，A/B 更快。
