# 04 · 换词表 = 模型作废

## 现象
想压缩词表（30000 → 8000），在旧模型上续训，结果全乱。

## 根因
BPE 重训后 **token → id 的映射全变了**：同一个词，新旧词表里的 id 不同。
旧模型权重对齐的是旧映射，一旦加载新 tokenizer，权重就对不上了。
（实证：同一句"你好世界"，旧词表编码成 `[4285, 8957, 27833]`，新词表是 `[5298, 1152]`。）

## 修复
换词表必须走完整链路，**模型从头重训**：

```sh
uv run python data/chinese/train_tokenizer.py --vocab-size 8000   # 1. 重训分词器
uv run python data/chinese/prepare.py                             # 2. 重编码数据
uv run python training/train.py ... --out_dir=out/新实验名         # 3. 模型从头训
```

## 怎么避免
tokenizer 是模型和数据之间的"共同语言"，**换语言必须重学**：

- 想保留模型继续训 → 永远不要动 tokenizer
- 想换 tokenizer → 接受模型从头重训，旧 checkpoint 作废

> 这也是为什么"换数据源"和"换词表"是高成本操作：它们都隐含着模型重建。
