## 关键洞察
- RL 教 2.7M 学的是**行为形式**(何时收尾/何时续、怎么像人说话、别乱码), 非**知识/推理**。
- "像人说话"是序列分布可学的 → coherence/反坍缩 reward 有效。
- "真理解/算对/多轮记忆"需要 容量承载 (a,b)→s 或 实体→观点 的映射, 2.7M 存不下。

## 给用户的方向建议(醒来决策)
1. **若目标是"能稳定对话的小模型"**: 当前 rl_coh_dialog 已达实践边界(健康稳定单轮通顺),
   可部署。再多轮 RL 收益边际。
2. **若想要"真理解/数学/多轮"**: 需换更大模型(>2.7M)或换架构(记忆已探索), 单独立项。
   不建议在 2.7M 上继续 RL 调参 —— 已四套铁证无突破。
3. **若数学是硬目标**: 走"工具化/格式化"(模型输出公式+截断, 外部算)或受限解码, 不追求真算。
4. **可低成本再试**: 扩充更真实的闲聊语料做 SFT(warm-start 知识)再 RL —— 但受容量制约,
   预期改善有限(基座数据质量天花板, 见 README A/C)。
