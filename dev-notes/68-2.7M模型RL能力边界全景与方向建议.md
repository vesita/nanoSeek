2.7M(6层×80d×4头) 治理后 SFT 基座 + 多轮 RL 能力边界已探明: **稳定性/"会说顺话"已解决; 真理解/真计算/多轮是容量天花板, 继续 RL 调参无突破。**

## 关键洞察
- RL 教 2.7M 学的是**行为形式**(何时收尾/续、像人说话、别乱码), 非**知识/推理**。
- "像人说话"序列分布可学 → coherence/反坍缩 reward 有效; "真理解/算对/多轮"需容量承载 (a,b)→s 或 实体→观点 映射, 2.7M 存不下。

## 方向建议(醒来决策)
1. **要"稳定对话小模型"**: rl_coh_dialog 已达实践边界(单轮通顺稳定), 可部署; 再多轮 RL 收益边际。
2. **要"真理解/数学/多轮"**: 需换 >2.7M 模型或换架构(记忆已探索), 单独立项; 不建议在 2.7M 上继续 RL 调参(四套铁证无突破)。
3. **数学硬目标**: 走"工具化/格式化"(输出公式+截断, 外部算)或受限解码, 不追求真算。
4. **可低成本再试**: 扩充更真实闲聊语料 SFT(warm-start 知识)再 RL, 受容量制约预期有限(基座数据质量天花板, 见 README A/C)。
