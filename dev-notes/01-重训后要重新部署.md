# 01 · 重训后要重新部署（runtime 模型是快照）

## 现象
重训出一个新的 `best.pt`，去跑 Rust 对话，效果还是旧模型的（甚至更差）。

## 根因
`convert.py` 把 checkpoint 转成 `runtime/model.safetensors`，这是一次性**快照**：
训练出的新权重不会自动更新到 runtime 目录。重训后如果忘了重新 convert，部署的永远是"上次转换时的模型"。

## 修复
重训后必须重跑转换，再重新打包：

```sh
uv run python inference/runtime/scripts/convert.py --ckpt out/<实验名>/best.pt --dataset chinese
uv run python inference/scripts/package.py --ckpt out/<实验名>/best.pt
```

## 怎么避免
把部署物当"拍照片"而不是"镜子"：训练出结果 → 手动/脚本重新 convert → 再部署。
养成习惯：**每次训练完，都要过一遍部署链路**。排查"模型效果不对"时，第一件事就是
检查 runtime 目录里 `model.safetensors` / `model_config.json` 的时间戳是不是最新的。

> 本例实证：runtime 里是 18:50 的旧 checkpoint，用户 19:03–19:14 又训了 6000 步，
> 但部署的模型完全没更新，导致调试时误以为是新模型不行。
