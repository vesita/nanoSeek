# 74-交替课程学习实证：冷启动预热与语言-算术交替回放的动态平衡与容量约束

## 1. 背景与核心假设
在之前的研究中，我们在极小算术模型（`nano_arith`, 485k 参数）上验证了进位电路可以快速收敛并对字面噪声具备不变性（Note 70-73）。
用户提出关键假设：
> **能否在项目的 4.5k 字级大词表基础模型架构（3.39M 参数，含 MoE、KV 记忆、CSA）上，先进行算术冷启动预热，再进行少量语法训练，随后进行算术复训；即采用「300 步算术冷启动 + 28 轮（100 步语言对话 $\leftrightarrow$ 20 步算术回放）」的交替推进模式，在保证模型算术能力不强烈下降的情况下，逐步学习自然对话？**

本实验旨在探索：在模型容量有限（3.39M 参数）且词表高达 4,533 个 Token 的情况下，逻辑运算回路与海量自然语言在梯度交替冲刷下的动态平衡机理。

---

## 2. 实验设置与执行过程
* **模型架构**：项目标准基础架构（6 层，4 头，80 维，MoE 8 专家 top-2，带 KV Memory 动态记忆、CSA 压缩滑窗、Attention Sinks、QK-Norm），参数量 **3,386,000 (3.39M)**，词表 4,533；
* **从零初始化**：权重完全从 scratch 随机初始化；
* **数据流**：
  * **自然语言**：`data/chinese/train_char.bin`（4,583 万 Token），Assistant Mask 机制；
  * **算术生成流**：带紧凑 Scratchpad 进位链（`c`）与 50% 字面扰动（加/加上/等于几？）的 1~3 位加法题；
* **课程周期计划**：
  * **阶段 0（冷启动）**：300 步高密度加法算术训练（LR 从 0 预热至 1e-3）；
  * **阶段 1~28（交替推进）**：共 28 轮循环。每轮 100 步语言对话 + 20 步算术回放，累积语言训练 2,800 步（严格吃透 1 个完整语言 Epoch，4,587 万 Token），算术回放 560 步；
  * **总步数**：3,660 步。

## 4. 深度机制剖析与核心结论

### 4.1 语言能力的极佳收敛性
在 28 轮交替推进中，语言验证集 Loss 从 5.3889 顺滑收敛至 **2.9359**（与不加算术的常规 1-epoch 基线表现完全一致）。
输出采样表明：模型成功学会了中文常用词汇搭配与对话句型（如 `“我们是的,我们是一个...”`），证明**在语言训练中穿插算术回放，完全不会损害主干语言模型的表征学习能力与收敛速度**。

### 4.2 逻辑能力的“擦除-重写”非对称性（Asymmetric Plasticity）
通过双轨探针，我们捕获到了极小模型在大词表下的一个深刻生理现象：
1. **词表稀疏与 Grokking 门槛**：
   在 `nano_arith`（词表仅 56）中，300 步足以让模型发生 Grokking 并收敛到 100% EM；但在 4,533 维字级大词表中，数字与加减号的 Embedding 梯度更新只占极小一部分，300 步仅够完成“语法格式对齐”（产生 `1c1`、`0c1` 等进位形式），进位因果权重尚未彻底“固化”。
2. **语言海量梯度的淹没效应（Flooding Effect）**：
   每一轮 100 步语言训练所带来的梯度方差极大（覆盖 4,500 万字语料中的几千个汉字），会迅速冲刷尚未固化为深层子空间的加法逻辑；
3. **20 步回放的弹性上限**：
   20 步回放能将算术表现从完全失忆拉回至局部偶发唤醒（2.5% EM），并保留了对数字与加法符号的敏感度（如模型在面对 `45+78=` 时输出带有 `7c7` 的进位特征序列，而非随机文字），但无法全面抗衡 5 倍步数的通用语言擦除。

## 5. 启示与下一步演进路线
本实验首次在 nanoSeek 完整架构上跑通了**“预热冷启动 + 交替回放”**的跨模态课程范式，证实了该框架在工程与数值上的高稳定性。基于上述结论，若要实现算术逻辑与自然对话的真正共存，推荐以下优化路径：
1. **非对称步数比率调整**：将交替比率从目前的 `100 步语言 : 20 步算术` 调整为 `50 步语言 : 50 步算术`，或者在每步中直接采用 **Data Mixing（混合批次：80% 语言 + 20% 算术同步更新）**，消除“先学后擦”的时序颠簸；
2. **参数隔离与 MoE 路由特化**：利用 2.7M 架构内置的 8 个 MoE 专家，通过特定 Loss 引导将 1~2 个 Expert 专门约束为“算术逻辑专家”，避免通用语言前向更新直接覆盖算术专家的权重；
3. **充分 Grokking 后再接入语言**：在 Stage 0 将算术冷启动延长至 1000~1500 步，直至进位回路在拓扑上彻底固化后，再引入温和的语言微调。
