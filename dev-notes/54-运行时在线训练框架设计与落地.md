## 1. 架构定位

传统大模型（70B+）由于显存占用过大、反向传播慢，无法在用户对话中做实时在线学习。  
而 **nanoSeek 拥有 2.70M 超小参数量（单步前反向 <15ms，显存 600MB）**，天然支持端侧在真实对话中**即时自进化**。

---

## 2. 运行时反馈闭环设计

```
                       用户输入 (Prompt)
                             │
                             ▼
                    流式自回归打字机生成
                             │
                             ▼
                   展示回复给用户，等待反馈
                             │
      ┌──────────────────────┼──────────────────────┐
      │                      │                      │
      ▼                      ▼                      ▼
  输入 ++ (点赞)         输入 -- (点踩)       输入 !corr <回答> (纠错)
      │                      │                      │
      ▼                      ▼                      ▼
 异步触发正向强化       异步触发负向打压       异步微单步 SFT 强化
 (Advantage > 0)       (Advantage < 0)       (Target Cross Entropy)
```

---

## 3. 指令集与安全隔离机制

1. **实时互动反馈**：
   - `++` 或 `+`：点赞好评（指数放大正向奖励 $A > 0$，推高该回答策略）。
   - `--` 或 `-`：点踩差评（指数放大负向惩罚 $A < 0$，逆向压低坏回答策略）。
   - `!corr <正确答案>`：用户直接教学，以目标答案执行 1 步微 SFT。
2. **安全与隔离**：
   - `!save [路径]`：将会话中演进出的个性化权重沉淀保存为独立 Adapter。
   - `!reset`：一键出厂复原，基座模型永远不受单次坏更新污染。
   - `!status`：实时查看本会话中累积的点赞、点踩与微调次数。
3. **算法稳定性保障**：
   - 指数奖励塑形：$\tau = 1.5$ 放大奖惩反差。
   - 终止符神经元静默：EOS 位置计算 L1 能量正则。
   - 基座 KL 散度针：$\beta = 0.03$ 约束策略不偏离合法中文语法。
