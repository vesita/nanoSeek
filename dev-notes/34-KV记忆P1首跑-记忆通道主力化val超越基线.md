# 34-KV记忆注意力P1首跑：记忆通道主力化，val 超越基线

对象：`out/obs_mem/best.pt`（synth，400 步，best val **8.0443** @ step 200）
对照：`out/obs_kv/best.pt`（synth，基线 CSA+HCA，best val **8.2842** @ step 300）
同种子 1337、同数据、同配置，仅 use_kv_memory=true / use_hca=false（+ compile 关）。

## 结果

| 指标 | 基线（HCA） | 记忆（KV记忆） |
|---|---|---|
| best val | 8.2842 @300 | **8.0443 @200**（−0.24，更优且更早收敛） |
| 长程通道贡献 | glob 0.09-0.14（最弱） | **mem 2.2-7.2（主力通道）** |
| K 有效秩 | 6.4-11.2 / 20 | 3.6-6.9 / 20（更低秩） |
| V 有效秩 | 2.2-6.3 / 20 | 1.6-3.5 / 20（更低秩） |
| 每步耗时 | 0.8s（compile） | 2.0s（eager，顺序扫描） |

## 解读

1. **记忆通道被模型重度使用**：观测台实测 mem 输出范数 2.2-7.2，是原 HCA（0.09-0.14）
   的 10-50 倍——模型学会用可写状态承载长程信息，而不是像 HCA 那样近乎闲置。
2. **val 提升 −0.24**：同种子同数据下的直接对比，可学习遗忘/写入状态 > 静态平均摘要。
3. **KV 更低秩**：记忆模型把 KV 压得更紧凑（K/V 有效秩全线下降）——低秩假设更成立，
   记忆 latent 甚至可能从 16 再往下压。
4. **训练代价**：顺序扫描 256 步 × 6 层与 torch.compile 不兼容（编译卡死，eager 2s/步）；
   400 步 ≈ 14 分钟。后续优化：chunk 并行（GLA 论文做法）恢复 compile 友好。
