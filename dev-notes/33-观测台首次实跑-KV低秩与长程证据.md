# 33-观测台首次实跑：KV 低秩、长程证据与滑窗近均匀

对象：`out/obs_kv/best.pt`（修复滑窗掩码后基线，synth，best=step300，6 层×4 头×20 维，CSA 块16/topk4/窗64 + HCA + Sinks + MoE；8batch×8×256）。

## 关键数字
- K 有效秩 **6.4~11.2/20**、V **2.2~6.3/20** → 低秩（K 占 ~40%、V 占 ~1/4 维度）
- K 范数 **1.000±0.000** → QK-Norm 生效；sink/头 **0.076~0.126** → 每头 ~10% 预算进垃圾桶
- 窗内衰减 δ=0 **0.050（≈3×均匀）**、δ≥1 **0.009~0.026** → 近均匀无邻接偏好
- 块路径质量 **0.78~0.84**、超窗占比 **42%**、最远 p50 ~105-110 / p95 ~212-224
- 路径贡献 comp 0.08-0.20 / win 0.33-0.55 / glob 0.09-0.14
- 头间余弦：对角外均值 ≈0、最大 0.10-0.22（4 头正交）

## 结论（供 KV 记忆设计）
1. **KV 高度冗余 → 记忆可做小**：K 秩 ~8、V ~5，MLA 式低秩 latent 成立，P1 GLA 的 S 用 latent l=8~16。
2. **长程信息真实 → 全局记忆不是摆设**：42% 块质量在窗外、p95 达 ~220 token（16-token 压缩块）。
3. **HCA 最弱 → 记忆模块天然替换槽位**：glob 0.09-0.14 < 窗路径 0.33-0.55；换"静态平均摘要"为可学习记忆收益最高。
4. **注意力对距离不敏感 → 固定滑窗边界可疑**：窗内近均匀（语义 > 距离），64 token 硬边界或切断远距语义；"逐通道可学习衰减"记忆契合。
5. **sink 稳定占 ~10% 质量** → 记忆路径保留持久/垃圾桶槽位。
