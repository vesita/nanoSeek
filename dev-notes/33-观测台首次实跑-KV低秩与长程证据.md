# 33-观测台首次实跑：KV 低秩、长程证据与滑窗近均匀

对象：`out/obs_kv/best.pt`（修复滑窗掩码后的基线，synth，best = step 300，val 8.2842，
6 层 × 4 头 × 20 维，CSA 块16/topk4/窗64 + HCA + Sinks + MoE）。8 batch × 8 × 256 聚合。

## 结论（直接喂给 KV 记忆设计）

1. **KV 空间高度冗余 → 记忆状态可以做小**：K 有效秩 ~8、V 有效秩 ~5，
   MLA 式低秩 latent 完全成立；P1 GLA 的记忆矩阵 S 用 latent l=8~16 就能装下
   大部分信息（l×l 状态，每头几百个浮点）。
2. **长程信息真实存在 → 全局记忆不是摆设**：块路径 42% 质量在窗外、p95 到达
   ~220 token。模型确实在消费远距离信息（以 16-token 压缩块的形式）。
3. **HCA 是最弱长程通道 → 记忆模块的天然替换槽位**：glob 贡献（0.09-0.14）
   明显小于窗路径（0.33-0.55）。把 HCA 的"静态平均摘要"换成可学习、可更新的
   记忆状态，是收益最高的改造点。
4. **注意力对距离不敏感 → 固定滑窗边界可疑，可学习遗忘有据可依**：
   窗内近均匀（没有"邻接优先"），说明语义关联 > 距离；64 token 的硬边界
   可能切断了本有用的远距语义——而"逐通道可学习衰减"的记忆状态天然契合
   这种距离无关的注意模式。
5. **sink 稳定占用 ~10% 质量**：记忆路径里也值得保留一个持久/垃圾桶槽位。

## 附带结论
- 滑窗掩码修复后 best val 8.2842 vs 修复前 8.3198（同 300 步，synth）——
  修复正确且带来小幅提升（之前模型把容量浪费在看未来上，推理时又看不到）。
- 旧观测结果（out/obs_kv/old/stats、out/ab_test1/base/stats）都是带 bug 或
  未训练的模型，不可作为设计依据；本笔记数字是第一个可信基线。
