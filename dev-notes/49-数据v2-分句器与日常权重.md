# 49-数据v2：分句器 + 日常对话权重提升

## 动机（用户指示 2026-08-30）
1. **分句器**：训练数据按"句"组织，模型像人一样按完整句子阅读/生成——
   不硬截断句子。中文用 。！？… 分句、英文用 .!?; 分句、换行/空格作为标识。
2. **数据权重更偏日常对话**：话术再降、闲聊拉满。

## 方案
### 分句器（data/chinese/split_sentences.py）
- 规则分句（保留标点）：
  - 中文句边界：。！？…（全角）+ .!?（半角，数字小数点保护）
  - 英文：.!?; + 换行
  - `用户：/模型：` 行不拆；换行保持句分隔
- 超长句（>80 字）再按逗号/分号切（防整段一长句）
- prepare.py 加 `--split-sentences` 开关（默认关，数据 v2 开启；内存中分句，不改 txt）
