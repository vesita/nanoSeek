# 51-极小模型前沿技术调研与nanoSeek优化路线

## 一、调研背景
nanoSeek 在消费级硬件（8GB 显存 / AMD RX 6600）上探索 1M~10M 参数极小模型，核心挑战：在受限参数预算与训练步数内最大化非线性表达力、消灭对话重复坍缩、消除词表冗余与话术固化。
本文调研 2024~2026 年 Ultra-Small LMs / Edge LLMs 核心突破，形成演进路线图。

## 二、前沿技术

### 1. 输入表征：Token-free / Byte-level
- **Meta BLT (2024)**：抛弃 BPE，原生 UTF-8 字节输入；字节熵预测器在信息熵超阈值处动态切 Byte Patch 压缩为 Latent Token，输出端解码回字节。价值：消除 BPE 把咨询话术合并为高频 Token 的顽疾；相较固定 3 字节聚合窗，自适应 Patching 保持高压缩比且不破坏汉字边界。
- **汉字偏旁/部首/笔画因式分解**：4,600+ 常用汉字拆为「214 康熙部首 + 400 声韵母 + 5 种基本笔划」。嵌入表 4,600 → 700 以内，嵌入参数 11 万 → 1.5 万（−86%），彻底杜绝生僻字 OOV。

### 2. 拓扑与参数复用
- **MobileLLM (2024)**：深窄优于浅宽——固定参数下 12~16 层深窄架构的归纳偏置与逻辑推理大幅超越 6 层浅宽。
- **块级跨层权重共享**：第 i 层与 i+1 层共享核心 Attention 与 FFN 投影矩阵，各自保留独立 RMSNorm、门控标量、RoPE 偏移。物理参数保持 6 层（~2.5M~3.0M），有效计算深度等价 12 层前向。
- **Universal Transformer**：2~3 个强力 Block 循环迭代 2~3 轮，配可学习循环步数门控。

### 3. 线性注意力与神经记忆
- **Google Titans (2024.12)**：传统无条件累加 S_t = r·S_{t−1} + k_t v_t^T 会被日常废话/套话填满黑板，造成键值混叠与检索精度下降。解法是 Surprise Metric + 动量记忆梯度更新 S_t = (1−α_t)S_{t−1} + η_t·∇L_surprise(x_t)：仅高信息量 token 强力写入，低信息量套话忽略。
- **RWKV-7 / DeltaNet 矩阵记忆律**：动态先擦后写 S_t = r·S_{t−1} + β(v_t − S_{t−1}k_t)k_t^T，配通道特异性衰减，实现长程状态精准联想。

### 4. 部署量化：BitNet b1.58
- 1.58-bit 纯三值化：W ∈ {−1, 0, 1}，激活保持 8-bit / 16-bit。
- 收益：① GEMM 退化为整数加减累加，降低内存带宽与功耗；② 3M 参数全量权重仅 ~600 KB，单核 CPU 推理 200+ tok/s；③ 契合 Rust Candle 原生运行时。

### 5. 对齐与长程一致性
- **SimPO**：无需 Reward Model，直接用长度归一化对数似然差值 L = −log σ(β/|y_w|·log π(y_w|x) − β/|y_l|·log π(y_l|x) − γ)；500~1000 条闲聊 vs 套话对比对微调即可清洗顽固话术。
- **MTP 自蒸馏**：t+1/t+2 辅助头输出与主干下一步 Logits 算 KL 一致性损失，无需额外数据提升多步语义规划。

## 三、落地路线图
- **阶段 1（已落地/进行中）**：字级因式分解 Embedding；KV 记忆输出门控 + RMSNorm；细粒度 MoE 8选2 + 7层加深；2-Step MTP 辅助前瞻。
- **阶段 2（下一阶段优选）**：MobileLLM 块级权重共享（7 层物理 → 14 层逻辑深度）；Titans 惊喜度门控（记忆抗套话污染）；SimPO 极轻量无 Reward 偏好对齐。
- **阶段 3（长远探索）**：BLT 动态自适应字节 Patching；BitNet b1.58 三值化 Rust 极速运行时。

## 四、结论与决策
1. **短期验证**：当前 7 层全要素 3.02M 架构已融合 MoE、KV 门控与 MTP 辅助，作为现阶段基准最扎实。
2. **中期突破点**：网络结构上最值得尝试 **MobileLLM 式跨层权重共享**（3.0M 参数换 12~14 层非线性表达力）与 **SimPO 话术排斥对齐**。
