# 60-对话语料治理：剔除任务碎片/噪音，保留日常对话

日期 2026-09-03
核心脚本: `training/govern_dialogue_data.py`
治理备份: `data/chinese/_backup_<ts>/` | 剔除源: `data/chinese/_discarded/`

## 动机
模型生成"不通顺/碎片拼贴"的根因在数据（dev-notes/21, 29, 59）：
`zhuangxialie`(149MB, 38%) 是任务模板/NLP 推理碎片，`multi_turn` 是极端话术固化。
用户要求「保留日常对话数据」，据此做全量分类治理。

## 全量分类核查 (probe: 多轮度 / 字符多样性 d1 / 任务标记 / 咨询词)
| 源 | 规模 | 多轮度 | d1 | 判定 |
|---|---|---|---|---|
| zhuangxialie | 210,740块/149MB | 0.94 | 低 | 任务碎片(对对联/NLP推理)，剔除 |
| multi_turn | 100,000块/133MB | 5.50 | 0.0005 | 445字/条、咨询词99% = 话术固化，降权 |
| dsh | 2,561块 | 0.09 | — | CI 命令回显噪音，剔除 |
| shareai | 18,229块 | 0.08 | — | 单轮谜题/问答任务，剔除 |
| lccc | 150,000块 | 1.58 | 0.020 | 真实短闲聊，全量保留 |
| glm | 42,530块 | 2.68 | 0.011 | 中长对话(有翻译腔)，保留 |
| zhihu_kol | 136,934块 | 1.00 | — | 长篇连贯KOL，保留 |
| kdconv / muice / identity / dailychat | 少量 | — | — | 优质补充，保留 |

## 治理动作 (prepare.py --source-ratio, char_level)
- 剔除 train+val: zhuangxialie / dsh / shareai → 移入 `_discarded/`（prepare 遍历 *.txt 不再读）
- 降权 train 侧: multi_turn 0.15（保留 15% 作"倾听/共情"能力来源；val 保持全量 90/10）
- 其余日常对话源全量保留

## 结果 (train 侧, 字级)
| 指标 | 治理前 | 治理后 | 变化 |
|---|---|---|---|
| 样本数 | 644,235 | 336,205 | **-47.8%** |
| 字级 token | 140.7M | 46.4M | **-67.0%** |
| val token | 7.5M | 7.5M | 0 (仅对话源, 跨实验可比) |

## 用法 / 可复现
```bash
# 首次治理(含备份+快照)
.venv/bin/python training/govern_dialogue_data.py
# 仅重跑 prepare(数据源已移好, 只重生成 bin)
.venv/bin/python data/chinese/prepare.py --char-level --insert-eos \
  --source-ratio multi_turn_dialogue.txt=0.15
# 回滚: 把 _discarded/* 移回 data/chinese/, 再把 _backup_<ts>/* 拷回
```
