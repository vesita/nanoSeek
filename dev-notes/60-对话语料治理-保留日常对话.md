# 60-对话语料治理：剔除任务碎片/噪音，保留日常对话

日期 2026-09-03
核心脚本: `training/govern_dialogue_data.py` | 备份: `data/chinese/_backup_<ts>/` | 剔除源: `data/chinese/_discarded/`

## 动机
"不通顺/碎片拼贴"根因在数据（dev-notes/21, 29, 59）：`zhuangxialie`(149MB, 38%) 是任务模板/NLP 推理碎片，`multi_turn` 是极端话术固化。用户要求「保留日常对话数据」，据此全量分类治理。

## 全量分类核查 (probe: 多轮度 / d1 / 任务标记 / 咨询词)
- **剔除**：zhuangxialie（210,740块/149MB，多轮度0.94，d1低，对对联/NLP推理碎片）、dsh（2,561块，0.09，CI 命令回显噪音）、shareai（18,229块，0.08，单轮谜题/问答）
- **降权**：multi_turn（100,000块/133MB，5.50，d1=0.0005，445字/条、咨询词99% = 话术固化）
- **全量保留**：lccc（150,000块，1.58，0.020，真实短闲聊）、glm（42,530块，2.68，0.011，中长对话有翻译腔）、zhihu_kol（136,934块，1.00，长篇连贯KOL）、kdconv/muice/identity/dailychat（少量，优质补充）

## 治理动作 (prepare.py --source-ratio, char_level)
- 剔除 train+val: zhuangxialie / dsh / shareai → 移入 `_discarded/`（prepare 遍历 *.txt 不再读）
- 降权 train 侧: multi_turn 0.15（保留 15% 作"倾听/共情"来源；val 保持全量 90/10）
- 其余日常对话源全量保留

## 结果 (train 侧, 字级)
- 样本 644,235 → 336,205（**−47.8%**）；字级 token 140.7M → 46.4M（**−67.0%**）；val token 7.5M → 7.5M（0，仅对话源，跨实验可比）

## 用法 / 验证
- 首次治理: `.venv/bin/python training/govern_dialogue_data.py`；仅重跑 prepare: `prepare.py --char-level --insert-eos --source-ratio multi_turn_dialogue.txt=0.15`
- 回滚: 把 `_discarded/*` 移回 `data/chinese/`，再拷回 `_backup_<ts>/*`
- `train_char.bin` 可正常 memmap (46.4M token)，分布健康；train.py char_level=True 时读 train_char.bin（line 283/285）。
- git: `_backup_*/` `_discarded/` 已加入 .gitignore，不进版本库。
