# 03 · prompt 格式要和训练数据一致（全角 vs 半角冒号）

## 现象
Rust REPL 里输入对话，模型输出很差 / 认不出对话结构。

## 根因
训练数据的对话格式是 `用户：…` `模型：…`（**全角冒号**），
而 REPL 喂给模型的是 `用户: …` `模型: …`（**半角冒号**）。
`：` 和 `:` 是**不同的 token**，模型训练时从没见过"半角冒号开头"的对话，等于换了一种语言。

## 修复
REPL 拼 prompt 时改成和训练数据逐字符一致：

```rust
context.extend(tok.encode(&format!("用户：{line}\n模型："))?);
```

## 怎么避免
- 训练/推理的 prompt 模板必须**逐字符一致**，包括全角/半角、空格、换行。
- 写推理端之前，先用 `grep "模型：" 数据 | head` 确认训练数据真实格式，
  别凭印象猜（本例数据里 `用户：…\n模型：` 之后紧跟答案，**无空格**）。
- 排查"模型不认 prompt"：把训练数据和推理 prompt 分别编码成 token 序列，逐位对比，
  差异一眼可见。
