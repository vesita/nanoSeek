# 38-1500步重训评估-长训让记忆优势翻倍

## 背景
dev-notes/37 C 项：chunk 并行落地后记忆/基线重训到 1500 步再评估（400 步=0.1 epoch 欠训练；dev-notes/36：EOS/结构属欠训练）。

## 训练结果（同种子 1337、同数据、同步数、batch 64）
- base1500：best val 3.8546@1350，最终 3.8763（1350 后略回升），~20 min。
- mem1500 (C=32)：best = 最终 **2.8479**@1500，24:50（1.36 it/s），val 全程单调降无过拟合。
- 记忆优势随训练拉大：400 步 −0.538 → 1500 步 **−1.007**（val 双倍差距）；两模型都未饱和，下次可考虑 3000 步。

## 工程（dev-notes/37）
C=64@batch64 OOM → kv_memory_chunk 入 config，C=32 + compile=true → 1.36 it/s（与基线同速）；1500 步 25 分钟可复跑，P2 Delta 擦写迭代成本可控。

## 对话智能度（eval_dialogue，30 样本）
- mem1500：avg_len **47.5**、rep2 **0.0264**、rep3 **0.0041**、ws 3%、d1 **0.8139**、d2 **0.9858**。
- base1500：avg_len 79.8、rep2 0.0445、rep3 0.0051、ws 3%、d1 0.7334、d2 0.9765。
- 记忆回复更短集中、重复更少、多样性更高；400 步（dev-notes/36）rep3 0.0 vs 0.054 → 现 0.0041 vs 0.0051，长训后基线重复也大降，记忆优势缩窄但仍领先。

## 多轮（eval_multiturn，3 场景 × 4 轮追问）
- mem1500：EOS **83%**、自开轮 0%、平均 len 83.6、rep3 **0.013**、末轮 len **101.3** / rep3 **0.012**。
- base1500：EOS 25%、自开轮 0%、平均 len 104.2、rep3 0.020、末轮 len 120.0 / rep3 0.027。
- EOS 25% → 83%：记忆模型学会"把话说完"，基线仍 3/4 顶满 120 token；无硬崩溃（rep3>0.3 或长度≤2 均 0）。

## 手动三轮验证（用户要求：你好 → 名字 → 年龄；T=0.8, top-k=200, rp=1.2）
- **base1500**：三轮全答非所问、句子粘连，第三轮顶满 120 token 不 EOS，绕在套话里。
- **mem1500**：同样不答事实问题，但成句；两轮自然收尾（59/55/103 tok），第三轮 103/120 内收尾；咨询师式二选一追问且两轮不换句式。
- **限制（非缺陷）**：两模型都无法回答"你叫什么名字/多大了"；2.85M 参数 + 语料无自指信息，记忆结构解决"上下文长程引用/状态保持"非百科知识，要报名字需在语料设定身份（系统提示 + 自指样本），是数据问题非结构问题。

## 结论
1. 长训双赢，记忆赢得更多（val −1.007、EOS 83% vs 25%、结构成形 vs 粘连）。
2. dev-notes/36"欠训练"判断成立：EOS 率/重复率随训练大幅改善。
3. 1500 步仍未饱和，下一步：P2 Delta 擦写律 A/B（dev-notes/37-B），或加自指样本/身份设定测事实性记忆（数据侧验证记忆通道）。
4. 机制猜测：状态矩阵天然"摘要保持"，回复更短集中或源于用记忆通道压缩上下文。
