# 对数放缩门控混合（LSE gate-mix，v2）：可学习 α 找到「线性学力 ∩ LSE 抗重复」的甜点

> 接 dev-notes/22（LSE 实现）与 23（纯 LSE 硬替换 A/B：机制验证成立但代价过高）。
> 用户要求「和之前网络层结合」——把纯替换修正为**可学习门控混合**。
> 实验 2026-08-15，RTX 5060，seed 1337，1500 步，关 mHC（与 lin/lse 对齐）。

## 改动（v2，可学习 α）

残差合并从两种极端改成第三态：
```
纯线性:  x ← x + F(x)                    # lin 臂 (α≡1)，val 0.8042
纯 LSE:  x ← LSE(x, F(x))                # lse 臂 (α≡0)，val 3.5898
门控混合: x ← α·x + (1-α)·LSE(x, F(x))，α = sigmoid(raw_gate)   # gate 臂，α 可学习每层标量
```
- `use_lse_gate`（新开关），与纯 `use_lse_residual` 互斥、**不与 mHC 互斥**。
- 每层 1 个可学习标量 `raw_gate`，初始 0 → α₀=0.5（线性/LSE 均衡起点）。attn/ffn 两子层共享同一 α。
- 参数量仅 6（n_layer=6），几乎可忽略。

## 实验结果 1：val loss（越低越好）+ 学到 α

| 臂 | 残差合并 | val@1500 | 学到 α |
|----|----------|----------|--------|
| lin | 纯线性 | **0.8042** | α≡1（固定） |
| gate | 可学习混合 | 2.6766 | l0:0.67 → l5:0.54（见下） |
| lse | 纯 LSE | 3.5898 | α≡0（固定） |

**学到 α 有清晰深度梯度**（关键洞察）：
```
layer 0: α=0.67 (raw 0.715)   ← 浅层偏线性
layer 1: α=0.65
layer 2: α=0.62
layer 3: α=0.59
layer 4: α=0.54
layer 5: α=0.54                ← 深层偏 LSE
```
模型自己学到了「浅层（词法/结构）多走线性累加，深层（尖刺累积处）更多走有界 LSE」——这正好命中「深层是 SwiGLU 尖刺/过度自信累积最重的地方」这一先验。

## 实验结果 2：对话智能度（统一 6 prompt × seed，eval_dialogue.py）

| 模型 | val@1500 | rep3↓(抗重复) | turns↑(轮次结构) | 观感 |
|------|---------|----------------|-----------------|------|
| **gate** | 2.6766 | **0.0372** | **1.7** | 有真实轮次/回话话术，重复大幅下降 |
| lin | **0.8042** | 0.0873 | **1.8** | 低 loss 但明显重复 |
| lse | 3.5898 | 0.0239 | 1.5 | 几乎不重复但语义碎片化 |

## 核心结论：gate-mix 是甜点，设计目标达成

在「对话智能」这个用户最关心的维度上，gate-mix **同时拿到了两头的优点**：
1. **抗重复 ≈ 纯 LSE**：rep3 = 0.037，是纯线性(0.087)的 **2.4 倍低**，接近纯 LSE(0.024)。
2. **对话轮次结构 ≈ 纯线性**：turns = 1.7，与 lin(1.8) 基本持平、明显优于纯 LSE(1.5)。

即「既有 LSE 的抗尖刺/抗过度自信，又不牺牲线性残差的表征学习/对话结构」——这正是 gate-mix 的设计初衷，被实测验证。

**代价是 val loss**：2.68 比纯线性 0.80 高。但这正印证 dev-notes/14 的观察：**「val 更低 ≠ 采样更好」**——纯线性虽然 loss 最低，却因过度收敛而重复坍缩；gate-mix 用更高的 loss 换来了更不重复、轮次更完整的输出。在 user 关心的「对话智能」上，gate 是最均衡的。

## 后续方向

- **调 α 起点/范围**：现从 0.5 起。可试 α₀ 洗成更偏线性（如 0.7 起），看能否在保持低重复的同时把 loss 压向 0.8。
- **α 与 mHC 叠加**（v2 已兼容）：gate-mix + mHC 是自然组合，值得跑。
- **per-sublayer α**（attn/ffn 各一个）而非共享：看 FFN（SwiGLU 尖刺源）是否该更偏 LSE。
- α 的最终值可看作「模型认为每层需要多少 soft-max 抗尖刺」的**可解释探针**——值得可视化随训练 evo。

## 诚实标注

- 单次 seed 1337、1500 步、batch 64。gate 臂从 0.5 起学，val 2.68 是「较均衡」的形态，但**未必是最优 α 起点**；后续可做多起点消融。
- val loss 客观比 lin 高：若纯以 loss 为目标，linear 仍是 winner；gate 的价值在于**对话智能（重复↓+结构完整）**这个维度。
