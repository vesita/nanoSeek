## 1. 核心洞察：为什么要"按句输入"？
标准多轮强化训练若把全部历史文本拼接进 Prompt：
- 标准的 Casual Self-Attention 会直接在显式 Token 上走"捷径"做点积；
- 导致 **P1 KV 联想记忆通道 $M_t = M_{t-1} + K_t V_t^T$ 无法获得任何梯度回传压力去真正存储与召回信息**。

"按句输入"的设计本质：
- 模型在第 $K$ 轮**只能看到当前这单个句子的 Prompt**（输入长度仅 ~15-25 字）；
- 前序轮次的实体（姓名、城市、偏好、事件）在原始输入中完全不存在；
- 唯一跨轮信息通路是模型内部的 **KV 记忆矩阵状态 $M$**；
- 结合多轮实体召回奖励，策略梯度直接逼迫 KV 记忆读写投影层升级为高保真联想存储器。

## 2. 双模型交替对话互训系统 (`dual_chat_selfplay.py`)
同时启动两个独立的 2.70M Agent（Alice 👩 与 Bob 👨）：
1. **交替发消息**：Alice 发送单句 $\rightarrow$ Bob 接收并结合自身记忆 $M_B$ 给出下一句 $\rightarrow$ Alice 接收继续承接；
2. **实时质检与策略梯度**：每轮回答由另一方结合客观奖励指标（相关性、句式自然度、无复读、利落吐 EOS、神经元静默）计算指数奖励 $R$，说话方立即后台单步策略梯度更新；
3. **认知融合 (Model Soup)**：讨论完成后自动融合双方权重，产出更强健最优检查点。

## 3. 运行命令
