# 69-RWR/GRPO 混合训练: 奖励引擎与词表联合学习 (用户提案验证)

日期 2026-09-04（日间; 接 68 方向建议）

## 提案
用户: "奖励引擎可以和词表混合着学" —— 不再两阶段 (SFT 基座 → RL 后训),
而是把奖励引擎信号直接混进基座训练目标, 每个优化步同时优化:
  1. 语料 next-token CE (学词表/语言结构)
  2. 奖励引擎打分的采样候选 → 加权信号 (学"奖励引擎认可的输出")

## 实现
training/rl/rwr_mixed_char.py (支持 --rl_mode grpo|rwr):
  loss = λ_ce·CE(语料, assistant-mask) + λ_rl·RL项 + β_kl·KL(→基座) + λ_q·EOS静默
  复用 sampler / RewardEngine / grpo_char 提示词池与语感门控
  对照口径: 同起点 (cont_v1_1epoch) + 同步数 (300), 对标 rl_coh_dialog (纯 GRPO)

## 关键发现 1: RWR (softmax 加权模仿) 在 2.7M 上必塌 (v1/v2/v3 三次实测)
- 现象: 三种配置 (纯语料CE/全token、加KL兜底、加Anti-Dwarf+winsorize+门控修正)
  全部在 step 30~200 间塌向空回复: 均长→0~2, 乱码 53%, 多样性 62%, 无法恢复
- 根因 (结构性, 非调参): **RWR 权重恒正 (softmax), 只"模仿"高分候选, 从不"压制"
  低分候选**。2.7M 小模型采样出的"次优壳"(如 `"`、二字残句) 一旦拿到相对高权重
  就被模仿 → 自我强化 → 塌缩。GRPO 的组相对优势**可正可负**, 负优势主动压低坏输出,
  这是稳定性来源 (rl_coh_dialog 300 步健康, 均长 8-20)。
- 其他踩坑 (均已修):
  - 语料 CE 必须 assistant-mask (与基座 SFT 同目标); 全 token CE 让模型学"预测用户
    轮次" (loss 5.0 vs masked 2.5), 目标错位
  - 退化时 KL/EOS 静默必须全程在场 (不能随 RL 权重一起清零), 否则模型无锚点漂移
  - masked CE + MTP 辅助 loss: 窗口有效 token 极少 (<~32) 时 MTP targets 全 -100 →
    cross_entropy 0/0 = NaN → 需 min_valid 窗口过滤重采样
  - 退化门控"组最佳"必须是 argmax 奖励候选的长度, 不是组内最短 (v2 用 min 导致
    几乎每步都误判退化 → RWR 全程清零 → 塌)

## 关键发现 2: 混合的正确姿势 = GRPO + 语料 CE 同场 (v4)
- 把 RWR 换成 GRPO (组相对优势) 后冒烟 40 步健康: 均长 9~21.5 与 rl_coh_dialog
  健康轨迹一致, 退化步 2/40, CE 语料正常下降 → 混合目标在稳定机制下可行

## v4 全量结果 (300 步, 同起点 cont_v1_1epoch, dialog_quality 两轮取中)
| 指标 | cont_v1_1epoch (基座) | rl_coh_dialog (GRPO300) | rl_mixed_v4 (GRPO+CE 300) |
|---|---|---|---|
| 乱码字占比 | 9% | 5~7% | **2~3%** |
| 均长 | 11.5 | 19~20.4 | 26.1~26.8 |
| 多样性 | 100% | 100% | 100% |
| 温和确认腔 | 0/8 | 2/8 | 1~2/8 |
| 退化步/300 | - | ~稀疏 | ~6 |
| 主观样例 | 碎片 | 套话但通顺 | 更自然的"先松一点/不急着"话术, 碎片最少 |

## 结论
1. **"奖励引擎和词表混合着学"成立, 但机制必须是 GRPO 组相对优势, 不是 RWR**:
   RWR (softmax 恒正权重, 只模仿不压制) 在 2.7M 上三次实测全塌 (均长→0);
   换成 GRPO (可负优势主动压制坏输出) + 语料 CE 同场后 300 步健康。
2. **语料 CE 混合带来可复现增益**: 乱码 2-3% < 纯 GRPO 的 5-7%, 均长更稳
   (26+ vs 19-20)。词表学习在场 = 更强的语言锚, RL 更少漂移。
3. 结论口径: 混入语料 CE 的 GRPO 是"更稳的 GRPO", 而非"更聪明的模型" ——
   收益在语言稳定性, 不在理解/算术 (容量天花板不变, 见 dev-notes/68)。
4. 产物: out/rl_mixed_v4/best.pt (新最佳对话模型, 建议后续对话部署用它)。

## 怎么避免
- 小模型上"奖励信号混合进基座训练"要用**可压制坏输出的机制** (GRPO 组相对优势),
  不要用恒正权重的 RWR 模仿 (只学正样本 = 喂大小模型自己的次优输出 = 必塌)
- 语料 CE 目标必须与基座 SFT 一致 (assistant-mask)
- 退化兜底 (KL+静默) 全程在场; masked 目标 + 辅助 loss 防全 ignore 窗口 NaN
