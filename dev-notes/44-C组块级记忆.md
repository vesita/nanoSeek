# 44-C组：块级记忆（块摘要流递推，粒度变粗实验）

## 动机
- P1 记忆是**逐 token** 写入（每 token 外积更新状态 A∈R^{l×l}）→ 256 token/层。
- 观测台：K 有效秩 ~8/20、V ~5/20；记忆通道主力化但**粒度假设未验证**——
  记忆需要多细的写入粒度？块级写入（C 个 token 一个摘要条目）是否无损？
- dev-notes/42：记忆计算非训练瓶颈（MoE FFN 是）→ C 组价值 = 表达力/粒度实验 +
  为更大模型（显存/计算受限）铺路，不承诺训练加速。

## 设计：块级写入 + 逐 token 读取（P1 chunk 公式的块级化）
- 块大小 `kv_memory_block`（token 数，默认 1 = 走原 P1 chunk 路径，回归对照）。
- 块 b 摘要（池化在投影后，mean over 块内 token，pad 用有效计数）：
  k̂_b = mean(k_m[块])，v̂_b = mean(v_m[块])，r̂_b = mean(r[块])，ŵ_b = mean(w[块])
- 块级衰减 Ĝ = cumsum(log r̂)；状态 S_{b+1} = exp(ĝ_b) ⊙ S_b + ŵ_b ⊙ k̂_b v̂_bᵀ
- 读取（逐 token）：o_t = exp(ĝ_b) ⊙ (S_b·q_t) + persist·q_t，读块**开始**状态
- **因果与语义**：P1 是写后读（o_i 含自身写入）；块级读前写——块内 token 不读本块
  摘要（避免块内未来 token 均值泄漏），**块内局部信息由 CSA 滑窗（w=64 ≥ 块 16）兜底**。
  C=1 时块级 ≠ P1（漏自身写入项，~5e-3 级）——设计使然；默认 block=1 走原路径不变。
- Tb 很小（C=16 → 16 块）顺序循环，无需 chunk 并行。

## 实施踩坑（v1 → v2）
- **v1 读前写 bug**：读取用块开始状态、更新在读取后 → 被读取的状态恰好都不含
  r 贡献（块 0 状态=0、块 1 状态=w₀k₀v₀ᵀ 无 r、末块更新被丢弃）
  → **mem_forget 梯度全断（0/8）**。
- **v2 修复**：读取加逐通道衰减因子 o_t = exp(ĝ_b)⊙(S_b·q_t) + persist·q_t
  （与 P1 chunk 公式同构），r̂ 全程参与梯度 → mem_forget 8/8 ✅。
- 附带发现：use_csa 模式下 c_attn 是**既有死参数**（CSA 用 c_qkv_csa，c_attn
  从未被调用 → 无梯度，每层 ~12.5K 参数，block=1 同样存在）。删除会破坏老
  checkpoint 加载（strict），暂不动，留待专门处理。

## 验证
1. fp32：块级方法 vs 手写参考实现 **逐位一致（max|Δ|=0）**；block=16 全记忆参数有梯度 ✅
2. 3 步训练冒烟（GPU）
3. 300 步 A/B：A=out/b_full_300（block=1，val 5.3096 已有）；B=out/c_block16_300
   （--kv_memory_block=16，同 seed/schedule）。验收：B val 不劣于 A（±0.02）。

## 计算收益（C=16, T=256）
- 状态更新 256 → 16 次（−94%）；chunk einsum 消失（块序列直接循环）
- q 投影 / 读取 matvec / mem_up 逐 token 不变 → 记忆总计算约 −40~50%

## 结果：❌ 块级记忆假设被否定（300 步 A/B，2026-08-30）
| 配置 | val @300 |
|---|---|
| A 逐 token（block=1，对照） | **5.3096** |
| B 块级（block=16） | 5.5469（+0.237） |

- 粒度粗化（16 token 一个摘要条目）明显损性能 → 记忆需要**逐 token 写入**。
- 与 B 组（分层）同向：**"记忆简化"方向（降粒度/删层）全部被否定**——
  观测台"低利用"证据（读写比低、K 秩低）不能直接推导"可删减"：
  记忆是端到端学出来的结构，删减改变优化景观。
- 记忆当前形态（全层 + 逐 token + latent 16）接近局部最优；
  真正的冗余方向未找到（秩方向 1500 步已验：latent 8 略逊）。

## 结论
- C 组代码保留（kv_memory_block 参数），默认 1 行为不变。
- 快速测试（300 步）三连否定：latent 8（1500 步才见分晓）、分层、块级。
  后续结构实验应转向**增强**方向（如 dev-notes/39-#2 Delta 擦写精度）
  或验收性 1500 步（不承诺快速测试能筛出差异）。
