# 43-B组：记忆分层（kv_memory_layers，只开高层记忆）

## 依据（观测台 dev-notes/33）
- 高层记忆读写比 0.41-0.48 vs 底层 0.25-0.27 → 底层利用率显著低；假设底层 CSA 已够局部信息、记忆通道冗余 → 只开高层无损。

## 方案
- `kv_memory_layers: Optional[int] = None`：None = 全开（默认，兼容现状）；n = 只开**最后 n 层**；0 = 全关；非记忆层回退 HCA（与 use_kv_memory=False 完全一致）。
- `CausalSelfAttention(config, layer_idx)`：`kv_memory_enabled = use_kv_memory and (kv_layers is None or layer_idx >= n_layer - kv_layers)`；`Block` 传 layer_idx（MTP 辅助 Block 默认 0 → 生效时 MTP 记忆一并关闭，可接受）。
- config_loader 放宽类型检查：train.py 默认 None 时允许 yaml/命令行覆盖（`--kv_memory_layers=3` 不再 TypeError）。

## 验证
1. fp32 等价：None vs =n_layer 输出逐位一致（max|Δ|=0）；每层记忆参数 10,788，layers=3 时减半（316,192 → 305,404）。
2. 3 步冒烟（layers=3：loss 11.77→11.43，checkpoint 正常）；稳态 ~1.1 it/s。
3. 300 步 A/B（同 seed 1337 / 同 GLM 数据 / 同步数）：A = out/b_full_300 全开（C=32 无 checkpoint）/ B = out/b_layers3_300 layers=3；验收 B val 不劣于 A（±0.02）。

## 结果：❌ 假设被否定（300 步 A/B，2026-08-30）
| 配置 | val @300 | 参数 |
|---|---|---|
| A 全开（None） | **5.3096** | 3.04M |
| B 只开最后 3 层 | 5.5240（+0.214） | 2.93M |

- B 全程落后 A（step 30 起即差 ~0.2，非末段拉开）→ 底层记忆**并非冗余**：读写比虽低（0.25 vs 0.41）仍贡献早期拟合容量；"读写比低"≠"可删除"。
- 速度无差异（A/B 均 ~1.19 it/s）：记忆计算不是瓶颈（MoE FFN 是），分层无速度收益。
- **决策：记忆分层不做。** 代码保留（kv_memory_layers），后续大模型/长序列显存紧张时可按需开高层（当前 3M 无显存压力）。
