# 43-B组：记忆分层（kv_memory_layers，只开高层记忆）

## 依据（观测台 dev-notes/33）
- 高层记忆读写比 0.41-0.48 vs 底层 0.25-0.27 → 底层记忆利用率显著低。
- 假设：底层 CSA 已提供足够局部信息，记忆通道冗余 → 只开高层无损。

## 方案
- 新配置 `kv_memory_layers: Optional[int] = None`：None = 全部层开记忆（默认，兼容现状）；
  int n = 只开**最后 n 层**的记忆（top-n）。
- 非记忆层回退 HCA 全局摘要路径（与 use_kv_memory=False 行为完全一致）。
- 实现：`CausalSelfAttention(config, layer_idx)`，`kv_memory_enabled = use_kv_memory and
  (kv_layers is None or layer_idx >= n_layer - kv_layers)`。
- MTP 模块的辅助 Block 用默认 layer_idx=0：kv_memory_layers 生效时 MTP 记忆一并关闭
  （辅助模块，可接受，注释说明）。

## 验证
1. fp32 等价性：kv_memory_layers=None vs kv_memory_layers=n_layer（=全开）输出逐位一致；
   参数量：kv_memory_layers=3 时记忆参数减半（3.04M → ~2.44M）。
2. 300 步 A/B（同 seed 1337/同 GLM 数据/同步数 schedule）：
   - A = 当前默认全开（新跑，C=32 无 checkpoint）
   - B = kv_memory_layers=3
   - 验收：B val 不劣于 A（±0.02 内）→ 记忆分层无损 → 阶段性训练省记忆计算。

## 结果：❌ 记忆分层假设被否定（300 步 A/B，2026-08-30）
| 配置 | val @300 | 参数 |
|---|---|---|
| A 全开（kv_memory_layers=None） | **5.3096** | 3.04M |
| B 只开最后 3 层 | 5.5240（+0.214） | 2.93M |

- B 全程落后 A（step 30 起即差 ~0.2，非末段拉开）→ 底层记忆**并非冗余**：
  虽读写比低（0.25 vs 0.41），仍贡献早期拟合容量。观测台"读写比低"≠"可删除"。
- 速度无差异（A/B 均 ~1.19 it/s）：记忆计算不是瓶颈（MoE FFN 是），分层无速度收益。
- **决策：记忆分层不做。** 代码保留（kv_memory_layers 参数），后续大模型/长序列
  显存紧张时可按需开高层记忆（当前 3M 参数无显存压力）。

## 实施细节
- `kv_memory_layers: Optional[int] = None`；None=全开、n=最后 n 层、0=全关。
- `CausalSelfAttention(config, layer_idx)`：`kv_memory_enabled = use_kv_memory and
  (kv_layers is None or layer_idx >= n_layer - kv_layers)`；非记忆层回退 HCA。
- `Block` 把 layer_idx 传给 attention（MTP 辅助 Block 用默认 0）。
- config_loader 放宽类型检查：train.py 默认值 None 时允许 yaml/命令行任意类型覆盖
  （`--kv_memory_layers=3` 不再报 TypeError）。
