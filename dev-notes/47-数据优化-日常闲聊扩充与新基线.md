## 重建方案（方案 A：val 纯净，跨实验可比）
```bash
python data/chinese/prepare.py --task-ratio 0.25 \
  --source-ratio multi_turn=0.2 \      # 心理咨询 47%→~6M tokens（话术砍 80%）
  --source-ratio zhihu_kol=0.5 \
  --source-ratio zhuangxialie=0.25 \
  --source-ratio lccc=1.0 --source-ratio kdconv=1.0 \   # 新闲聊全量（不在白名单必须显式 1.0）

```
