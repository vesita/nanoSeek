# 开发笔记 71：nano_arith 任意位数与非对称算术突破（Scratchpad 进位链范式）

- **日期**：2026-03-29
- **实验目标**：攻克小模型"任意位数（1~6 位及以上）"与"高度非对称位数（如 2 位+6 位）"的算术泛化，引入 Scratchpad（思维链进位显式标注），突破纯自回归隐状态长距离进位失真。

## 1. 两大核心挑战
1. **非对称长度对齐**：如 `45 + 899999`，高位操作数为空，模型需自动学习"与 0 补齐并持续传递隐进位"；
2. **长距离链式进位饱和**：直接输出模式（如 `999999 + 1`）必须把 6 次进位累积信息完全压入固定维度隐状态，随序列增长注意力与 RoPE 频域信息衰减。

## 2. 方案：紧凑进位链草稿纸（Compact Carry Scratchpad）
生成数字时若该位向高位进位，模型显式输出专用进位标志符 `c`（`7+5=12` 输出 `2c`，`3+4=7` 输出 `7`）：
- `87 + 45 =`：个位 $7+5=12 \to$ `2c`；十位 $8+4+1=13 \to$ `3c`；百位 $0+0+1=1 \to$ `1`；序列 `2c3c1` $\xrightarrow{\text{提取数字反转}}$ `132`。
- 将内部隐状态传递转化为**外部显式自回归 Token 依赖**，释放注意力回路潜力。

## 3. 实验结果与评测
模型规格：4 层 Transformer，`d_model=96`，`n_heads=4`，`d_ff=288`（参数 48.1 万）；AMD APU 训练 4000 步（约 140 秒）。

**1~6 位全位数准确率（Held-out）：1/2/3/4/5/6 位均 100.0% EM**。

极限与非对称测试（CLI 实测）：
- `999999+1=` → `1000000` ✅ (Match)，Raw Scratchpad `0c0c0c0c0c0c1`
- `45+899999=` → `900044` ✅ (Match)，Raw Scratchpad `4c4c0c0c0c9`
- `123456+654321=` → `777777` ✅ (Match)，Raw Scratchpad `777777`

## 4. 结论与下一步
1. **48 万参数 Transformer 即具备媲美计算器的 1~6 位任意整数绝对精确加法能力**；
2. **Scratchpad（思维链 token）是打破自回归模型推理极限的关键技术**：把"计算过程"外显到上下文，降低隐层表示的维度负担；
3. **交付成果**：训练脚本与数据生成器支持 `--use_scratchpad`；交互式 CLI `nano_arith/cli.py` 支持即时大数演算；权重保存至 `out/nano_arith_scratchpad/best.pt`。
