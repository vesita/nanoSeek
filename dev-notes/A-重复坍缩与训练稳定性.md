## 病根（反复出现的同一件事）

1. **欠训练 = 重复坍缩**（06）：模型输出垃圾时先分层排查（数据/训练/部署），
   诊断三件套：① 看 top-10 logits（太平=没信心，某少见 token 独高=坍缩）② 解码 top token 看是不是
   `\n`/`'` 这类高频无意义 token ③ 对照数据统计排除格式问题。`模型：` 后紧跟换行在数据里 0 次，
   说明是模型把高频 token 当默认答案，不是数据格式。
2. **loss 骗低**（14/22）：交叉熵只惩罚不确定、不惩罚自信地错。SwiGLU 门控乘积冒极端值（同权重
   关钳制 max 6000+），在线性残差里逐层放大 → 模型押高频低信息 token（全角空格 U+3000）抄近道。
   这是比"词重复"更隐蔽的"坍缩形态"。

## 治理武器库（按实证时间线）

| 手段 | 证据 | 判定 |
|------|------|------|
| **Sinks**（11） | 单独开消除重复坍缩，loss 还略降（1000 步 4.27→4.21）；三重验证：开 Sinks 的一律不重复，与现实无关 | ✅ 进默认（必要不充分） |
| **Sinks 训满失效**（14） | 5000 步 val 1.297 历史最低，但采样全角空格死循环 | ⚠️ 训满（分布尖锐）必失效，只快不聪明 |
| **repeat-penalty**（16） | 解码端 CTRL 式惩罚，1.2 消除"先先先"卡壳，1.3 明显连贯 | ✅ 治标旋钮，default 1.1~1.3，RL 不是现在 |
| **LSE 残差**（22/23） | 有界残差 `LSE≤max+log2`，rep3 0.0239 = 线性臂 1/3.6；但硬替换学力 -2.8（val 0.80→3.59） | ⚠️ 机制成立，实现方式要改 |
| **LSE gate-mix**（24） | 可学习 α：浅层偏线性(0.67)、深层偏 LSE(0.54)；rep3 0.037 + turns 1.7 双优 | ✅ 甜点：抗重复 ∩ 线性学力 |
| **QK-Norm + Z-Loss**（25） | 2×2 A/B（1500 步）：QK −0.052 / Z −0.020 / **合开 −0.189（超线性，1.002→0.813）** | ✅ 近零参数，建议进默认 |
| **续训实证**（25 补充） | 4 臂 +500 步：qkz val 0.4905 最优，但采样 rep 全线回升约翻倍 | ⚠️ 再次印证"loss↔采样背离、训满失效" |

## 核心结论

1. **「val 更低 ≠ 采样更好」是贯穿始终的主线**：lin（0.80）重复最多、mem（0.936）乱码、lse（3.59）碎片——低重复不等于智能，判据永远是采样。
2. **架构能压窗口、压不掉根**：Sinks 必要不充分、训满必失效；抗尖刺路线（LSE→gate→QK/Z）把分布压住，只是把同一曲线平移；**训练预算 + 数据主导最终形态**。
3. **qkz 是当前最划算的稳定性组合**：+24 参数（QK）+ 0（Z），1500 步收敛快 0.19，建议默认 `use_qk_norm: true, z_loss_weight: 0.0001`。
4. **喟喋不休（不停机顶格生成）是另一类问题**：语料无 EOS 标记 + 数据回复普遍长（shareai 平均 396 字/92.6% ≥200）——治理方向在解码端（轮次边界截断/收紧长度/加强惩罚）与数据端（插 EOS 重训），不在架构。
5. **turn-level EOS 训练（26）直接把"停"学进分布**：每条模型回复后插 `<eos>` 重训，模型在无截断原始生成下 **6/6 prompt 自吐终止符**（非 EOS 臂 0/6），且 avg_len 200→78。这比解码端硬截断更本质——模型自己学会了"话说完→吐 <eos>"，解码遇 EOS 即停即可。
