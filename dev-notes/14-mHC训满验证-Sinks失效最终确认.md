# mHC 训满验证：val 历史新低，但重复坍缩回归（Sinks 训满失效的最终确认）

> 背景：dev-notes/13 后 mHC 进默认。早停 1500 步（val 3.31）判"平台"停太早，改禁早停训满 5000 步（`out/chinese-mhc-full`）验证 mHC 的智能收益。训练 2026-08-11。

## 结果

| 指标 | 值 | 对比 |
|------|-----|------|
| val loss @5000 | **1.2974** | v3（无 Sinks 5500 步）1.71，**历史最低** |
| "你好"采样 @seed42 | **3 样本全部重复坍缩 + 全角空格 U+3000 死循环** | 不可用 |

样本实况（节选）：`你好，货于疯于拍自然拍自然现场血各位水说他水我也不等，不，还：` + 一长串全角空格；`你好，借；打月打于疯于疯于�于疯于拍。` + 空格……

## 解读

1. **mHC 收敛效率再次确认，智能收益未兑现**：训满 loss 历史最低（1.2974 vs v3 1.71），但采样比 v3 的"悟空空空空"更糟——连词都不像了，纯坍缩到全角空格。mHC 与 Muon 同款：**只快不聪明**。
2. **Sinks 训满失效 = 最终确认**。此前 Sinks 只在训练中段（lr 高、分布不尖）验证有效，本实验补上了"训满（lr 归零、分布最尖锐）"场景。完整证据链：
   - v3 无 Sinks、训满 5500 步：val 1.71，重复"空空空"
   - 3000 步 A/B（Sinks 开、未训满）：val 1.93/2.74，采样仍重复
   - chinese-mhc-full（Sinks+mHC、训满）：val 1.297，重复 + 全角空格
   - 规律：**Sinks 是必要不充分——中途打破重复，训满（分布尖锐）必失效**。分布尖锐度是重复根因（与 eval-goal 已记录机制一致）。
3. **全角空格坍缩 = "loss 骗低"的极端形态**：对话数据里全角空格（缩进排版）是超高频又"低成本"的 token，模型押它抄近道压 loss，交叉熵只惩罚不确定、不惩罚自信地错（同 Muon 1e-2 教训）。

## 教训与开放方向

- **小模型"训满"未必优于"中途停"**：1500 步 val 3.31 破碎但**不重复**；5000 步 val 1.297 但**重复死循环**。都不可用，但"智能"（不重复）在中间态。
- 智能问题的核心仍是**重复坍缩**，Sinks 解决不了训满后的形态。
- 候选方向（**未验证**）：解码时重复惩罚 / length penalty；更强的 sink（更大偏置、自适应）；或接受"卡在训练中段"策略。真正根治可能要动注意力机制（如更强的 anti-collapse 正则）。

## 诚实标注

- mHC 的价值收敛在"训练效率"（训满 loss 历史最低），但用户目标（[[nanoseek-eval-goal]]）是**智能**——单点 mHC 无法交付智能，本实验是负结果。
- 全角空格是 BPE 下 U+3000 高频 token，本次坍缩目标从"词重复"变成"空白重复"，是同一机制的新形态，不是新问题。
