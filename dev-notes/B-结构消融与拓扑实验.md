## 方法论铁律（本主题最重要的产出）

1. **后训练不能注入新架构参数**（12）：`_build_model_from_checkpoint` 用 checkpoint 的 model_args
   覆盖命令行，加架构开关（Sinks 等）必须从 0 训。判断开关是否生效：查 checkpoint 里有没有对应参数名。
2. **"删连接"式实验必须做规模匹配对照**（18 的用户质疑 + 19 坐实）：前向跳过的参数 = 冻结废参数，
   **名义参数量 ≠ 有效参数量**。冻结删（B1, 2.62M 有效）与规模补齐删（B2, 2.85M）分开归因后：
   规模效应（+0.154 改善）和拓扑效应（+0.424 变差）都确认——**无注意力在匹配规模下依然独立有害**。

## 核心结论

1. **拓扑搜索 5 连败后关停"改/删已有通道"路线**：块内排序、删注意力×2、静态记忆全负结果——
   "全注意力 + attn_ffn + Sinks + mHC" 在小模型上接近局部最优。
2. **记忆 token 的教训最深刻**（20）：val 历史最低（0.9359）但采样崩坏——静态先验让模型在训练/验证
   时抄数据集级捷径（val 降 0.15 是捷径收益不是智能增益），自由生成时只能复读先验拼贴。
   **若只看 val，它是一个伪胜利**。与 Sinks 同构：固定锚点训满后都被利用成捷径。
3. **mHC 是唯一幸存者**：改连接方式不增参数，收敛加速 -0.34，与 Muon 同类（效率技术，val 可见收益；
   智能层面仍只有 Sinks 有干净证据）。
4. 下一步值得赌的：**输入条件化的读写机制**（真·工作记忆，成本高一个量级）或转向训练/数据维度。
