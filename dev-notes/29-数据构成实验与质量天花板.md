## 决定性发现：数据比例不是性格瓶颈

- multi_turn（100% 多轮）**也是情感支持话术**——A1 砍掉 zhuangxialie 后它占 ~75%，
  性格没变；
- A2/A3 把情感支持砍到 49% → 7%，**输出仍是话术碎片**（"你现在最让你放松不轻"、
  "先咱可以一点看哪句也没关系"）——说明话术 n-gram 是 BPE 统计里的高频结构，
  不是靠调比例能洗掉的；
- 真实闲聊源（dailychat 0.04M / muice 0.17M / shareai 0.98M / agent 0.09M）
  合计才 ~1.3M tokens，且 shareai 是 QA 题、agent 是技术对话——都不是"寒暄闲聊"。

## 质量天花板（诚实结论）

在「1500 步硬上限 + 现有语料」下，模型输出到达天花板：
- ✅ EOS 自吐 10/10、rep3≈0、回复短（50-70 token）——机制层面都解决了；
- ❌ **流畅度**：所有模型都是 BPE 碎片拼贴（1500 步 = 24.6M token 训练量，
  对 2.85M 参数模型学不出流畅中文）——这是**步数预算**的天花板，不是架构/数据可解；
- ❌ **性格**：只有心理咨询话术——这是**语料构成**的天花板，现有数据无解。
