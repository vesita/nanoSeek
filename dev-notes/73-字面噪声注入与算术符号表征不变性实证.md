# 73-字面噪声注入与算术符号表征不变性（Symbolic Invariance）实证

## 1. 背景与动机
`training/rl/reward/arith_rules.toml` + `arith_gen.py` 定义“配置生成基础规则 + 代码添加格式化噪音”：运算符 `+`/`＋`/`加`/`加上`/`加一加`；等号 `=`/`＝`/`等于`/`得`/`等于几？`/`等于多少？`；前缀与格式扰动 `问:`/`算:`/空格/全角数字。
此前已验证连续高斯噪声与 15% 离散标签翻转对进位神经元的强化（Note 72）；本实验引入**输入端字面噪声**，问：模型能否跨同义替换维持高精度？浅层如何把多变符号映射到同一因果算术空间？深层进位电路如何重构？

## 2. 方案与参数
- 架构：4 层 Transformer，`d_model=96`，`n_heads=4`，`d_ff=288`，约 48.5 万参数。
- 词表 56 字符：全角数字（０-９）、中文算术字元（加/上/等/于/得/几/多/少）、半角/全角符号与空格。
- 任务：1~3 位非对称加法（含 Scratchpad 紧凑进位链 `c`）。
- 字面噪声概率 $p_{\text{noise}} = 0.85$；学习率 $1.5 \times 10^{-3}$（Cosine 衰减）、Weight Decay 0.1；2500 步（ROCm APU 84.9 秒）。
- 权重：`out/nano_arith_literal_noise/best.pt`

## 4. 机制：符号表征不变性
- **Token Embedding 语义聚类**：`sim("+","＋")=+0.9604`、`sim("+","加")=+0.9172`、`sim("=","得")=+0.9775`、`sim("=","＝")=+0.9764`；对照 `sim("+","-")=+0.4405`、`sim("+","=")=+0.5752` → 自发形成算术语义流形，不同表面写法映射到同一拓扑邻域。
- **顶层隐藏状态完全对齐**（基准 `45+78=` 末 token，Layer 3 output）：`45加78=` **+0.9935**、`45加上78=` **+0.9975**、`45加一加78=` **+0.9888**、`４５＋７８＝` **+0.9981**、`45+78等于几？` **+0.9943**；对照减法 `45-78=` **-0.4585**（强负相关）→ 解码前深层状态已消除一切字面噪声（相似度 >0.99），统一归一化为纯净加法状态。
- **进位电路分层重组**（400 个中文/符号混合样本，$a_0+b_0 \ge 10$）：Layer 0 多字元吸收与字符对齐 $|r| \approx 0.48$；Layer 1 运算符消歧与特征抽取 $|r| \approx 0.58$；Layer 2 进位主逻辑中枢——Neuron #285 $r = \mathbf{+0.755}$、#119 $r = \mathbf{-0.747}$、#131 $r = \mathbf{+0.723}$；Layer 3 结果输出与 Scratchpad 格式对齐 $|r| \approx 0.57$。相比纯净模型进位中心在 Layer 1，**字面噪声促使进位逻辑迁往更深 Layer 2**，浅层（0-1）腾出专门消化自然语言表面多样性。
