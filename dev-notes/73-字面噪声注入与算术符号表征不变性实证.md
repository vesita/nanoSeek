# 73-字面噪声注入与算术符号表征不变性（Symbolic Invariance）实证

## 1. 背景与动机
在开发规范 `training/rl/reward/arith_rules.toml` 与 `arith_gen.py` 中，定义了“配置生成基础规则 + 代码添加格式化噪音”的思想：
* 运算符表面写法：`+`、`＋`、`加`、`加上`、`加一加`
* 等号表面写法：`=`、`＝`、`等于`、`得`、`等于几？`、`等于多少？`
* 前缀与格式扰动：`问:`、`算:`、空格扰动、全角数字扰动等

在之前的实验中，我们验证了连续高斯噪声和 15% 离散标签翻转噪声对进位神经元的强化效应（Note 72）。
本实验进一步引入**输入端字面噪声（Literal / Formatting Noise）**，训练微型算术模型，探究：
1. 模型能否克服同义替换与多字元表面扰动，维持高精度算术能力？
2. 模型的浅层表征是如何将多变的字面符号（如 `+`、`＋`、`加`、`加上`）映射到相同的因果算术空间的？
3. 深层进位电路在遭遇字面噪声冲击时，其分层结构如何重构？

---

## 2. 实验方案与参数
* **架构**：4 层 Transformer，`d_model=96`，`n_heads=4`，`d_ff=288`，参数量约 48.5 万。
* **词表**：扩展至 56 个字符，包含全角数字（０-９）、中文算术字元（加、上、等、于、得、几、多、少等）、半角/全角符号与空格。
* **训练配置**：
  * 任务：1~3 位非对称加法（含 Scratchpad 紧凑进位链 `c`）
  * 字面噪声概率：$p_{\text{noise}} = 0.85$（85% 的样本注入表面文字扰动）
  * 学习率：$1.5 \times 10^{-3}$（Cosine 衰减），Weight Decay：0.1
  * 训练步数：2500 步（ROCm APU 上耗时仅 84.9 秒）
  * 权重产出：`out/nano_arith_literal_noise/best.pt`

## 4. 机制可解释性分析：符号表征不变性（Symbolic Invariance）

### 4.1 Token Embedding 语义聚类
我们计算了嵌入层权重中不同字符的余弦相似度：
* `sim("+", "＋") = +0.9604`（半角与全角加号在嵌入空间高度重合）
* `sim("+", "加") = +0.9172`（汉字“加”与符号“+”自发聚类）
* `sim("=", "得") = +0.9775`，`sim("=", "＝") = +0.9764`
* 作为对照：`sim("+", "-") = +0.4405`，`sim("+", "=") = +0.5752`

**发现**：模型自发形成了算术语义流形，将不同表面写法的运算符映射到了相同的拓扑邻域中。

### 4.2 顶层隐藏状态的完全对齐
对比以 `45+78=` 为基准的最后一个 token 顶层表征（Layer 3 output）：
* `45加78=` $\to$ 余弦相似度 **+0.9935**
* `45加上78=` $\to$ 余弦相似度 **+0.9975**
* `45加一加78=` $\to$ 余弦相似度 **+0.9888**
* `４５＋７８＝` $\to$ 余弦相似度 **+0.9981**
* `45+78等于几？` $\to$ 余弦相似度 **+0.9943**
* 对照组（减法 `45-78=`） $\to$ 余弦相似度 **-0.4585**（强负相关）

**结论**：不管用户在前面输入的是“加一加”、“等于几？”还是全角“＋”，在进入解码阶段前，模型的深层隐藏状态已经**完全消除了一切字面噪声（相似度 > 0.99）**，统一归一化为纯净的加法状态！

### 4.3 进位电路的分层重组（Circuit Migration）
在探测 400 个含有中文/符号混合提示词的样本时，进位神经元（$a_0+b_0 \ge 10$）的分布呈现清晰的分层功能特化：
* **Layer 0**：主要负责多字元吸收与字符对齐，最大相关性仅 $|r| \approx 0.48$；
* **Layer 1**：运算符消歧与特征抽取，$|r| \approx 0.58$；
* **Layer 2（进位主逻辑中枢）**：
  * **Neuron #285**：$r = \mathbf{+0.755}$（极强进位触发神经元）
  * **Neuron #119**：$r = \mathbf{-0.747}$（极强进位抑制神经元）
  * **Neuron #131**：$r = \mathbf{+0.723}$
* **Layer 3**：结果输出与 Scratchpad 格式对齐，$|r| \approx 0.57$。

与此前纯净模型的进位中心在 Layer 1 相比，**字面噪声的引入促使模型将进位逻辑往更深层（Layer 2）迁移**，将浅层（Layer 0-1）腾出专门用于消化复杂的自然语言表面多样性！
