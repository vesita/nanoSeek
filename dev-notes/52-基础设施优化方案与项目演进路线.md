## 一、 基础设施优化方案（工程与算力效率）

### 1. 训练数据加载与流水线优化
- **当前瓶颈**：`train.py` 中的 `get_batch` 是单进程同步 `np.memmap` 随机切片，虽然内存占用低，但在每个训练 step 中与 GPU 前向串行执行。
- **优化方案**：
  1. **异步双缓冲加载器 (Async Prefetcher)**：封装轻量级 CUDA 数据预取线程（`prefetch_factor=2` + `pin_memory=True` + `non_blocking=True`），在前向反向执行的同时完成下一个 Batch 的切片与 Host-to-Device 传输，消除数据加载对 GPU 的空等。
  2. **Inductor 编译持久化缓存**：显式配置 `TORCHINDUCTOR_CACHE_DIR` 与 ROCm Triton 预编译产物持久化，消除反复启动时 5~6 分钟的重复 JIT 编译。
  3. **环境内存防 OOM 护栏**：在自动化训练脚本中设置虚拟内存软限制，并建立外部任务并发检测机制。

### 2. 推理与部署基础设施
- **当前瓶颈**：`chat.py` 与 `sample_py.py` 的自回归循环每 step 执行 `torch.cat`，产生反复的显存重新分配与拷贝。
- **优化方案**：
  1. **静态 KV Cache / 滑窗 Buffer (Static KV Buffer)**：
     - 预分配固定长度（`block_size=256`）的 KV 缓冲张量，自回归采样时以游标更新（In-place Write），显存分配次数从 $O(T)$ 降为 $O(1)$。
  2. **MTP 投机验证解码 (Speculative Decoding via MTP)**：
     - 现有模型已训练 2-Step MTP 预测头（具备预测 $t+1, t+2$ 能力）。
     - 推理端可直接落地 **MTP Speculative Decoding**：每步模型前向同时产出 2~3 个候选 token，下一步单次前向完成并行验证。打字机流式吞吐可提升 **1.8× ~ 2.5×**，无需额外的 Draft Model。
  3. **INT8 权重量化与 Rust 运行时导出**：
     - 将因式分解嵌入（24d）+ 6L MoE 权重导出为 INT8 / GGUF 格式，使 2.70M 模型整体内存 footprint 压至 **~1.5MB**，达到真正的边缘级超轻量常驻。

## 二、 模型架构与算法演进路线

```
                   ┌── 1. 词表演进：Byte-Fallback Char Tokenizer (100% 覆盖零 unk)
                   ├── 2. 推理加速：MTP Speculative Decoding (单步 2~3 token 投机验证)
nanoSeek 演进路线 ───┼── 3. 对齐优化：SimPO / DPO 极简偏好微调 (消除模板感)
                   ├── 4. 记忆增强：自适应时间衰减门控 (解决超长轮次上下文漂移)
                   └── 5. 语料治理：Data Mixture v3 (日常/百科/情感三元重平衡)
```

### 1. 词表与表征演进：Byte-Fallback 字符分词器
- **现状**：4623 词表覆盖了绝大部分常用汉字，消除了 BPE 的话术死锁，但在生僻字、特定专业英文符号或 emoji 时会退化为 `<unk>`。
- **演进目标**：
  - **WordLevel (4000 常用字) + 256 UTF-8 字节 fallback**。
  - 常用汉字保持 1 token 极速编码，非常规字符自动回退为 2~3 个字节 token。
  - 兼具字级模型的高效、无话术固化与字节直入的 100% 全覆盖、零 `<unk>` 优势。

### 2. 对话智能与偏好对齐 (SimPO / DPO)
- **现状**：模型在共情对话中语感良好，但受预训练语料分布影响，有时对非情感类指令也会习惯性给出安慰性回答。
- **演进目标**：
  - 构建 1000 条轻量级正负偏好对话对（$y_w$: 恰当回答 vs $y_l$: 答非所问/过早套话）。
  - 采用 **SimPO (Simple Preference Optimization)** 算法进行 200~300 步轻量偏好微调：
    $$\mathcal{L}_{\text{SimPO}} = -\log \sigma \left( \frac{\beta}{|y_w|} \log \pi_\theta(y_w|x) - \frac{\beta}{|y_l|} \log \pi_\theta(y_l|x) - \gamma \right)$$
  - 零额外参数、无需 Reward Model，使 2.7M 小模型学会“问天气答天气、倾诉时再共情”。

### 3. 长程记忆与话题切换机制
- **演进目标**：
  - 在 KV 记忆注意力中引入**自适应时间衰减项 (Adaptive Decay Gate)**：
    $$\gamma_t = \text{sigmoid}(W_\gamma x_t + b_\gamma)$$
    $$M_t = \gamma_t \odot M_{t-1} + (1 - \gamma_t) \odot \Delta M_t$$
  - 当检测到用户开始全新话题时，模型主动降低对前序记忆的保留权重，彻底避免多轮对话（>10 轮）中的上下文串味与历史干扰。
