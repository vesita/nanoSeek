# 稀疏注意力布线：删注意力有害且加重重复

## 背景（为什么做）

拓扑实验 A（块内子层顺序，dev-notes/17）排除"块内排序"后，试第二个维度：**注意力层稀疏布线**。假设：重复坍缩部分源于注意力层太多、都盯着近邻把局部模式固化，删掉一半注意力减少"死锁点"。

## 改动（Python-only，纯拓扑）

- `model/model.py`：`GPTConfig` 加 `no_attn_layers: list`（field(default_factory=list)）。列出的层索引跳过注意力（只跑 FFN 子层）。**参数保留但不参与前向 → 参数量严格不变（纯接线改变）**，state_dict 键名完整。
- `Block.forward` / `_mhc_forward`：`skip_attn` 分支。
- `training/train.py`：全局 + model_args + checkpoint 兜底。
- 配置 `train_chinese_sparse.yaml`：`no_attn_layers: [0, 2, 4]` → 布线 `l1:F | l2:AF | l3:F | l4:AF | l5:F | l6:AF`。

## 实验结果（2026-08-12，1500 步，seed 1337，对照 af = out/chinese-data2-af）

| step | af 全注意力 | sparse 稀疏布线 |
|------|------------|-----------------|
| 250 | 4.6243 | **4.5491** |
| 500 | 2.9083 | **2.8992** |
| 750 | **2.4640** | 2.5209 |
| 1000 | **1.9671** | 2.2526 |
| 1250 | **1.4509** | 1.9734 |
| 1500 | **1.0867** | **1.6647** |

采样目测（同 prompt 同 seed）：sparse 卡带式重复（"像是你像是你像是你"、"是结果是结果是结果"），对话轮次碎、绕；af 有来有回、能共情。

**结论：af（全注意力 + attn_ffn）大幅胜出。稀疏布线是明确的负结果，且比 fa（1.2543）更差（1.6647）。**

## 反证洞察（最有价值的部分）

删掉一半注意力让重复**更严重**。这反证了一个关键点：**注意力正是打破重复的机制**——FFN 是逐 token 独立变换，没有注意力去跨 token 聚合上下文，模型就只能复读最近的局部模式。Sinks 之所以有效，本质就是增强了注意力里的全局锚点。

## 归因修正（2026-08-12）：主因是规模缩小，不是拓扑

**质疑**（用户提出）：sparse 删注意力时"参数保留但不参与前向"——前向跳过的参数 backward 不经过、梯度恒 0、优化器不更新，**实为冻结的废参数**。名义参数量相等（2,849,036），有效训练参数却少了 3 个注意力层 = **230,484 / 8.09%**（CSA/HCA 注意力参数不小）。所以 sparse 同时变了"拓扑"和"有效规模"两个变量，重复上升无法归因。

**规模匹配对照**：6×76 全注意力（2,599,060 ≈ sparse 有效 2,618,552，差 0.75%），拓扑保留，1500 步。

| 臂 | 拓扑 | 有效规模 | val @1500 | 采样 |
|----|------|----------|-----------|------|
| af | 全注意力 | 2.85M | **1.0867** | 对话可用 |
| s76 | 全注意力 | 2.60M | 1.3591 | 严重卡带 |
| sparse | 删注意力 | 2.62M | 1.6647 | 严重卡带 |

**归因**：s76 与 sparse 采样一样卡带 → 有效参数缩到 ~2.6M 时，**拓扑不动也会崩向重复**。规模效应（af→s76，+0.27）与拓扑效应（s76→sparse，+0.31）都有，但**采样主因是规模缩小**，用户质疑成立。删注意力有独立小贡献（val +0.31），次要。

**方法论教训（最重要）**：名义参数量 ≠ 有效参数量。冻结/跳过前向的参数=有效规模变小。**"删连接"式拓扑实验必须做规模匹配对照**，否则结论不能归因于拓扑。

## 怎么避免 / 拓扑方向再校准

- "删注意力层"的结论需重新表述：**有效规模缩小 8% 才是重复主因**；删注意力独立贡献次要。单纯"减注意力层"不再优先试。
- 两次实验（块内对调、删注意力）都指向：现有架构的"全注意力 + attn_ffn"布线在小模型上接近局部最优，改既有通道接线换不来上限提升。
- 下一步值得赌的是**新信息通道**：记忆槽层 / 跨窗口横向记忆（显式长程载体，直击训满失效病根）。
- 任何新拓扑实验：**先保证所有参数真正参与训练**（不冻结、不跳过），再做规模匹配。
