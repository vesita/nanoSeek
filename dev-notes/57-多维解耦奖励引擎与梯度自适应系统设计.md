# 57-多维解耦奖励引擎与梯度自适应系统设计

日期：2026-09-01 · 核心模块：`training/rl/multi_reward.py`

## 1. 架构定位：告别单一标量盲盒
单一标量奖励易出作弊漏洞（"空回复不说话"得分高于"说错话"→ 静默塌陷）；多维解耦引擎拆为 6 维 $\mathbf{r}=[task, natural, anti\_repeat, anti\_robotic, quiet\_eos, sentiment]^T$：
1. `r_task`（任务/记忆/自发命名）：事实准确度、跨轮记忆召回、自选名字涌现
2. `r_natural`（自然度与长度）：8~65 字黄金节奏，严惩空回复（len=0 -> -5.0）
3. `r_anti_repeat`（抗复读）：3-gram 词频熵值，严惩车轱辘话
4. `r_anti_robotic`（去机械标签）：绝对零容忍 "用户/模型/user/assistant"
5. `r_quiet_eos`（利落收尾与静默）：正确吐 `<eos>` + 终止符隐藏层 L1 能量惩罚
6. `r_sentiment`（积极阳光与互动）：鼓励温暖回应、主动反问延续话题

## 2. 动态加权与梯度合成
- 加权综合 $S = \mathbf{w}^T \mathbf{r} = \sum_{k=1}^6 w_k r_k$；指数塑形 $R = \text{sign}(S)(e^{|S|/\tau}-1)$
- 多目标制衡（单维度无法走极端、互相约束达帕累托最优）；梯度指示清晰（反传带分项明细，杜绝"装哑巴"/"模板复读"）

## 3. 实机测试（`.venv/bin/python training/rl/multi_reward.py`）
- 自发命名与主动互动：+9.51 | R=+565.80（超大推力）
- 机械标签与心理套话：-5.57 | R=-39.99（强力抑制）
- 空回复装哑巴：-5.00 | R=-27.03（彻底熔断作弊路径）
