# 46-推理状态选择性续传（局部窗口 + 记忆状态缓存）

## 动机（用户指示 2026-08-30）
- 传统 transformer 的记忆 = 上下文本身：长对话必须把完整历史喂进注意力，
  上下文随对话增长（KV cache 只是省重复计算，不省输入）。
- 记忆黑板原理上 O(1) 表示全局历史 → 推理时**不必全量喂历史**：
  只喂最近局部窗口，窗口外信息由缓存续传的记忆状态承接。
- 目标：长对话推理输入固定小（≈窗口），不随对话轮次增长。
  用户明确：**只需要局部能续传就行**（轻量方案，接受长程信息近似）。

## 方案（最小可行版）
1. **记忆状态续传接口**（attention.py）：
   - `set_mem_state(state)`：把外部状态注入为递推初始值 A_in（替代恒 0）
   - `get_mem_state()`：返回递推末态（每层每头 (nh,l,l)）
   - P1 chunk / 块级 / Delta 三分支末尾统一记录末态
2. **模型层接口**（gpt.py）：`get_memory_state()/set_memory_state(states)`
   按层收集/注入（只遍历 kv_memory_enabled 层；MTP 推理不参与）
3. **推理循环**（sample_py.py）：
   - 输入 = 最近 K token（默认 K=64，与 CSA 滑窗 w=64 对齐）
   - 前向前注入缓存状态 → 前向窗口 → 取末位 logits → 采样 → 更新状态缓存
4. **RoPE 全局位置偏移**：窗口截断后 token 的绝对位置必须保持
   （RoPE 表扩到 block_size×4=1024，forward 接受 offset，attention 用 pos+offset 查表）
5. **选择性**：续传层数可配（默认全层；可只续传高层——B 组观测：
   高层读写比 0.41-0.48 承载主要记忆功能）

## 关键设计点 / 风险
- **训练/推理分布匹配**：训练时全序列 256 token、记忆从 0 递推；
  续传推理时输入只有窗口 → CSA 块/窗只能检索窗口内 token。
  窗口外信息完全依赖记忆状态 → 质量可能短期下降（模型没见过这种输入形态）。
- **配套训练截断**（后续可选）：训练时随机截断上下文起点 + 位置归一化/偏移，
  让模型学会"长程靠记忆状态" → 效果更好，但涉及数据管线 + 训练预算。
- 用户确认轻量优先：先做推理侧（不改训练），评估后决定是否配套。

## 验证
1. 单模型三路对比（多轮对话，eval_multiturn 改造）：
   完整上下文 vs 窗口+状态续传 vs 窗口无续传（记忆从 0）
2. 检查记忆状态是否携带跨轮信息（观测台：续传窗口下记忆输出范数应仍显著）

## 结果：✅ 窗口+续传 ≈ 完整上下文（eval_multiturn 3 场景 × 4 轮，obs_zh_mem1500glm）
| 模式 | EOS率 | 平均len | rep3 | 崩溃 |
|---|---|---|---|---|
| 完整上下文（基线） | 100% | 41.8 | 0.023 | 0 |
| **窗口64+续传** | **100%** | 46.0 | 0.033 | 0 |
| 窗口64无续传（对照） | 83% | 57.7 | 0.007 | **1** |

- **窗口+续传 ≈ 完整**：输入固定 64 token（不随 4 轮对话增长）而质量持平
  （EOS 100%、崩溃 0、长度相当）→ 用户目标达成：**长对话推理输入固定小**。
- **续传价值可量化**：无续传时 EOS 83%、崩溃 1（记忆每步从 0 → 窗口外信息全丢
  → 上下文断裂 → 收不住）→ 记忆状态确实承载了窗口外信息。
- 备注：rep3 无续传更低是噪声/保守回复，EOS/崩溃是更可靠的退化信号。
- 局限：单 seed 单次运行；窗口 64 内 CSA 滑窗恰好覆盖，模型对窗口外信息的
  依赖度有限（更小窗口可测记忆承载力极限，后续可选）。

## 关键实现点（备忘）
- 三分支（P1 chunk/块级/Delta）统一支持注入：`A_in = inj 或 zeros`，末态 `_last_mem_state`。
- RoPE 偏移：attention/block/gpt forward 加 `rope_offset`，查表 `cos[offset:offset+T]`；
  SwiGLU 加占位参数兼容 skip_attn 层；RoPE 表推理时扩展到 8192（buffer 替换，不影响权重）。
- 跨轮续传：eval 每轮 generate_ids 传 `resume_state`（上轮 get_memory_state 的末态）。
