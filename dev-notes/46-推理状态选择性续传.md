# 46-推理状态选择性续传（局部窗口 + 记忆状态缓存）

## 动机（用户指示 2026-08-30）
传统 transformer 记忆 = 上下文本身（KV cache 只省重复计算不省输入）；记忆黑板 O(1) 表示全局历史 → 只喂最近局部窗口，窗口外信息由缓存续传的记忆状态承接。目标：长对话推理输入固定小（≈窗口），不随轮次增长。用户明确：**只需局部能续传就行**（轻量方案，接受长程近似）。

## 方案与实现
1. **续传接口**（attention.py）：`set_mem_state(state)` 注入为递推初值 A_in（替代恒 0）、`get_mem_state()` 返回末态（每层每头 (nh,l,l)）；P1 chunk/块级/Delta 三分支统一注入/记录末态。
2. **模型层**（gpt.py）：`get_memory_state()/set_memory_state(states)` 按层收集/注入（只遍历 kv_memory_enabled 层；MTP 不参与）。
3. **推理循环**（sample_py.py）：输入 = 最近 K token（默认 K=64 = CSA 滑窗 w）→ 注入状态 → 前向窗口 → 取末位 logits → 采样 → 更新缓存；跨轮传 `resume_state`。
4. **RoPE 全局位置偏移**：窗口截断后绝对位置必须保持（RoPE 表扩到 block_size×4=1024，推理加载后扩到 8192；forward 传 offset，查表用 pos+offset；SwiGLU 加占位参数兼容 skip_attn 层）。
5. **选择性**：续传层数可配（默认全层；可只续高层——B 组观测高层读写比 0.41-0.48 承载主要记忆）。

fp32 验证 6.985e-10；注入状态确实改变 logits（Δ=0.0186，采样路径不变时输出可相同——记忆为辅助通道）。

## 关键设计点 / 风险
- **训练/推理分布不匹配**：训练全序列 256 token、记忆从 0 递推；续传推理只有窗口 → CSA 只能检索窗口内 token，窗口外信息全依赖记忆状态 → 质量可能短期下降。
- **配套训练截断**（后续可选）：训练随机截断上下文起点 + 位置归一化/偏移，让模型学会"长程靠记忆状态"，但涉及数据管线 + 训练预算；用户确认轻量优先，先做推理侧（不改训练）。
- 验证方式：三路对比（eval_multiturn 改造）+ 观测记忆输出范数仍显著。

## 结果：✅ 窗口+续传 ≈ 完整上下文（eval_multiturn 3 场景 × 4 轮，obs_zh_mem1500glm）
| 模式 | EOS率 | 平均len | rep3 | 崩溃 |
|---|---|---|---|---|
| 完整上下文（基线） | 100% | 41.8 | 0.023 | 0 |
| **窗口64+续传** | **100%** | 46.0 | 0.033 | 0 |
| 窗口64无续传（对照） | 83% | 57.7 | 0.007 | **1** |

- **窗口+续传 ≈ 完整**：输入固定 64 token（不随 4 轮增长）而质量持平 → **长对话推理输入固定小**。
- **续传价值可量化**：无续传 EOS 83%、崩溃 1（记忆每步从 0 → 窗口外信息全丢 → 上下文断裂）→ 记忆状态确实承载窗口外信息；rep3 无续传更低为噪声，EOS/崩溃是更可靠退化信号。
- 局限：单 seed 单次；窗口 64 内 CSA 滑窗恰好覆盖，对窗口外信息依赖有限（更小窗口可测极限，后续可选）。
