### 1.3 抽样读原文得到的四条关键事实

1. **手机号是真 PII，且集中出现。** 最危险的一段（#317）是 C# "从文本提取姓名电话地址" 题面，

## 2. 规则表（v2）

（`data/chinese/pii_scrub.py` 里的正则原文；顺序即优先级，重叠时高优先级胜出）

| 类别 | 正则（节选） | 占位符 | 校验器 | 说明 | 误伤风险 |
|---|---|---|---|---|---|
| `email` | `(?<!\\)[A-Za-z0-9._%+\-]+@…` | `<EMAIL>` | 无 | 标准邮箱；`(?<!\\)` 防字面 `\n` 的 `n` 被吞进 local-part | 低 |
| `url_cred` | `LB_ALNUM(?<!\\)scheme://user:pass@host` | `<URL_CRED>` | 无 | URL userinfo，整条替换 | 低 |
| `id18` | `LB_ALNUM\d{17}[\dXx](?![\dA-Za-z])` | `<ID>` | ISO 7064 + 合法生日 + 省级码 | 18 位身份证 | 加校验器后本语料否决 26/26 |
| `bank_card` | 4-4-4-4 分组 或裸 16~19 位，`lb_alnum('.','/')` 前缀 | `<BANKCARD>` | 非前导 0 + Luhn + **附近 20 字内必须有银行卡关键词** | 16~19 位银行卡 | 高；见 §2.1 |
| `mobile_cn` | `LB_ALNUM(?:\+?86[ -]?)?1[3-9]\d(?:[ -]?\d{4}){2}(?![\dA-Za-z])` | `<PHONE>` | 无 | 手机号，支持 +86/空格/连字符/**前置字面转义** | 中；11 位算术结果与俄文统计数会撞 |
| `landline` | `LB_ALNUM0[1-9]\d{1,2}[ -]\d{7,8}(?:[-转]\d{1,5})?(?![\dA-Za-z])` | `<TEL>` | 无 | 座机，**强制分隔符** | 低 |
| `qq` | `(?:QQ\|扣扣\|企鹅号…)\s*(?:号)?\s*(?:是\|为\|：\|=\|加\|联系)\s*\d{5,12}` | `QQ号：<QQ>` | 无 | **显式自述** QQ 号 | 低 |
| `wechat` | `(?:微信\|VX\|V信\|威信\|WeChat…)\s*(?:号\|ID)?\s*(?:是\|为\|：\|=\|加\|联系)\s*[A-Za-z][A-Za-z0-9_\-]{5,19}` | `微信：<WECHAT>` | 无 | **显式自述** 微信号 | 低 |
| `ipv4` | 标准四段 | `<IP>` | 无 | IPv4 | 高（教程 IP vs 我的 IP 不可分） |
| `plate` | `LB_CJK[省份字][A-Z][A-Z0-9]{4,5}[A-Z0-9挂学警港澳](?![A-Za-z0-9\u4e00-\u9fff])` | `<PLATE>` | 无 | 中国车牌（含新能源 6 位） | 中 |
| **`roster`（删块，不是脱敏）** | `find_roster_blocks()`：整块判定，见 §2.2 | **（整块删除）** | 不同手机 ≥3 且地址窗口手机 ≥3 且地址字 ≥12 | 姓名+手机+住址名单 | 见 §2.2 的间隔论证 |

**`LB_ALNUM`**（v2 新增，主 AI 复核抓到的漏检修复）：

```
LB_ALNUM = (?:(?<![\dA-Za-z])|(?<=\\[A-Za-z]))
```

第二分支豁免"反斜杠 + 单字母"的**字面转义**（`\n` / `\r` / `\t` / `\f` / `\v` …）。
宽度 2、定长，与定长 lookbehind 的择一在 Python `re` 里合法。
它**不会**误放行 `\alpha123...`（那要求紧邻两字符是 `\a`）。

**同坑排查（主 AI 要求"每条规则都过一遍"）** [实测] 单次全量：

| 规则 | 本语料是否存在"前置字面转义"的命中 | 是否改了边界 |
|---|---:|---|
| `mobile_cn` | **2 处**（真手机号，v1 漏检） | 改 |
| `landline` / `id18` / `bank_card` / `plate` | 0 处 | 改（同一 `LB`，保持同口径） |
| `email` / `url_cred` | 0 处，但存在"吞掉转义的 `n`"风险 | 加 `(?<!\\)` |
| `ipv4` | 0 处；其边界是 `[\d.]`，`\n` 的 `n` 不在其中，**本来就不会挡** | 不改（注释说明） |
| `qq` / `wechat` | 无左边界（关键字开头） | 不改 |

### 2.1 从实测假阳性反推出来的三条设计约束

1. **银行卡必须带上下文关键词。** 第一版"4-4-4-4 分组 + Luhn"全量跑出 3 处命中，抽读发现 2 处是错的：
   `2023 2024 2025 2026`（连续年份）→ `2023202420252026` Luhn 蒙对；
   MATLAB 数组 `[2000 2200 2400 2600 7200 7400 7600 7800]` → `7200740076007800` Luhn 也蒙对。
   4 连 4 位数字只要够多，蒙对 Luhn 是必然事件（约 1/10 × 候选数）。
2. **座机必须强制分隔符。** 无分隔符版本 64 命中，真座机只有 2 条，其余是 hex 串和小数。
3. **车牌省份字前不能是汉字**（`更新HEADER`）。

### 2.2 删块判据（v2 新增）与"为什么不是 10 块"

判据（两条同时满足，外加地址字兜底）：

```
A. 块内【不同】的 11 位手机号 >= 3
B. 至少 3 个手机号的 ±30 字窗口内有 >= 3 个地址指示字
   （地址字集合：省市区县镇乡村路街号栋室楼单元小区 + 繁体 縣鎮鄉號棟樓單元區）
C. 块内地址指示字总数 >= 12
```

**为什么加 B/C**：光靠 A（或主 AI 的参考判据"裸 11 位 + ≥6 地址字"）会把
"地址字多但**地址不挨着手机**"的正常块也判成名单。实测间隔（[实测] 单次全量）：

| 块 | 内容 | 不同手机 A | 地址窗口 B | 地址字 C | 判定 |
|---|---|---:|---:|---:|---|
| **#317** | C# 姓名/手机/住址提取题面 | **5** | **16** | 192 | **删** |
| #2989 | 俄文教育统计报表（5 个 `1x000000000` 形状巧合） | 5 | **0** | 94 | 不删（B 挡掉） |
| #1311 | `264503*69258` 算术 | 2 | 0 | 0 | 不删（A 挡掉） |
| #1567 | `301097F58FBE…` 位元组串/短信解码 | 1 | 2 | 14 | 不删（A 挡掉） |
| #90 | 查"中山市宏達戶外照明燈具廠電話" | 1 | 1 | 16 | 不删（A 挡掉） |
| #2842 | "如何用 Python 把 utf16 簡訊轉字串"教程 | 1 | 0 | 53 | 不删（A/B 挡掉） |

**A 的间隔是 5 vs 1，B 的间隔是 16 vs 0** —— 判据不是在噪声上拍出来的。
全量结果：**只删 1 块**（详见 §4.2）。

## 6. 我没能做到的部分

1. **零边界口径下 `1[3-9]\d{9}` 仍有 127 处**（数字边界为 0）。这 127 处全部是更长数字串的内部子串
   （大整数分解题、浮点尾数、时间戳、IMEI、URL 参数），抹掉会破坏题面。我**没有**自作主张改判据。
2. **只删了 1 个名单块**。判据是"≥3 个不同手机号 + 地址紧邻"，对**只有 1~2 个人的名单**、
   或**只有姓名+住址没有手机号**的名单不生效（§5 #17）。本语料未发现这类块，但**未做全量人名/住址统计**，
   所以"还有没有别的名单"我无法证明没有。
3. **手机号假阳性没有消除**，而且删块后占比更高：最终 15 处命中里 **8 处（53%）不是真人号**
   （2 处算术结果、5 处俄文统计数、1 处 SMS 教程示例）。形状上无法区分。
4. **IPv4 全量脱敏会动教程 IP**（298 处里私网/回环/文档地址占绝大多数），代码样例保真度下降。
5. **座机只认带分隔符的写法**，无分隔符一律漏检。
6. **没有处理 `new_sources/wildchat_zh.txt`**（同源 30.6MB，按指令不动），也没有跨文件做号码交集。
7. **`--inject-bug` 只覆盖了"规则永不匹配"这一种故障模式**；删块判据本身没有一个独立的
   "把它改坏会红"的注入点（只有正/负对照，能防漏删/误删，但不能证明判据代码里没有恒真分支）。
8. **Presidio 标记 33→31 是删块的副作用**。如果复核者认为"任何 Presidio 标记都不能消失"，
   那就与"整块删除"冲突，需要主 AI 裁决。
9. **自检的正对照与删块对照都是我构造的**，不是独立第三方标注。
