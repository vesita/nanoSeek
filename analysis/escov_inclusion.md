## 1. 六条规则（口径与证据）

| 规则 | 判据（assistant 回复上） | 通过条件 | 缺陷来源 / 证据 |
|---|---|---|---|
| `R1_rep3` | 3-gram 重复率：落在重复类型里的 3-gram 数 / 全部 3-gram 数，先剥所有空白，`len<6` 记 0.0 | `rep3 <= 0.3` | 重复折叠 1.66%（含 repass）、当场重复短语 0.8% [实测，`analysis/translate_escov.md` §10] |
| `R2_dup_phrase` | 存在长度 `L>=3` 使 `s[i:i+L] == s[i+L:i+2L]`（先剥空白） | 不存在 | 当场重复短语，如 `你好,你好,真遗憾`、`你住在哪里? 住在哪里?` [实测] |
| `R3_ascii_word` | `>=3` 个连续 ASCII 字母 | 不出现 | 未翻译英文词 2.5%、`我总是jelous`、`COVID已` [实测] |
| `R4_too_short` | `strip()` 后长度 | `>= 4` | 超短回复 2.0% [实测] |
| `R5_private_use` | 私用区 `U+E000`–`U+F8FF` 或替换字符 `U+FFFD` | 不出现 | 乱码 1.2%，如 `⊿闽玒\ue4c7и\ue7a4辨…` [实测] |
| `R6_cjk_ratio` | 汉字（`U+4E00`–`U+9FFF`）占比（去空白后） | `>= 0.6` | 未翻译/退化输出（`hii hi hi 喜 喜` 这类），[推断] 判据由本次定义 |

`rep3` 与 `data/chinese/clean_corpus.py::rep_n(t, 3)` 及 `inference/scripts/eval_dialogue.py::ngram_repetition` **逐字同口径**；阈值 0.3 是项目在干净源上标定过的（误伤 0.1%），**仅适用于短对话回复这个长度/结构**（`AGENTS.md §5.8`）。

对照设计（**每条正对照刻意只命中目标规则**，所以 `--inject-bug` 一定变红）：

- **正对照**：6 条规则 × 2 条应被拒回复，断言命中集 `== [目标规则]`。
- **负对照**：3 段完全干净的对话（中文标点 / 数字 / 问号）必须全留；user 轮塞进 `jelous`、私用区、当场重复、超短内容后**该段仍必须保留** —— 且先自证"同内容放进 assistant 轮会被拒"，否则这个免疫对照是恒真的空测试。
- **整段语义**：3 条回复里只有第 2 条（下标 3）不合格 ⇒ 整段丢，且精确报出 `(下标, 规则)`；换成干净回复 ⇒ 整段留。
- **逐字不变**：保留段必须是输入 JSON 的**同一对象**，序列化前后逐字一致。

### 3.3 user 轮与结构标签：原始文本里的命中是**预期**的

规则**只**判 assistant 回复。user 轮、`用户：`/`模型：` 标签、段间空行都会原样进文件。所以"把整份 txt 当一坨文本搜 6 条规则"**必然**命中；命中的来源全部可归因，不代表筛选失败：

| 来源 | 说明 |
|---|---|
| `用户：`/`模型：` 标签每行重复 | 让**整文件**的 rep3 虚高（标签本身互相重复），`模型：` 也会被 R2 当成重复子串的载体 |
| user 轮内容 | 用户拍板"user 轮不参与判定"，所以 user 轮里的英文词/乱码/超短内容**按设计保留** |
| 相邻两条 assistant 内容完全相同 | 跨轮重复，**单条规则看不见**（见 §3.4） |

保留段 user 轮里各规则的命中数（**描述性**，这些内容确实在输出文件里）：

| 规则 | user 轮命中数 |
|---|---|
| `R1_rep3` | 123 |
| `R2_dup_phrase` | 117 |
| `R3_ascii_word` | 191 |
| `R4_too_short` | 357 |
| `R5_private_use` | 8 |
| `R6_cjk_ratio` | 149 |

⇒ 验收口径应当是"**每条 assistant 回复**零命中"（本工具 §3.1 给出回复级命中数，独立复核脚本可重算）；把整文件当一坨文本搜得到的是**上述结构性命中**，不是漏筛。

### 3.4 相邻两条 assistant 内容完全相同（跨轮重复，未被规则覆盖）

保留段里连续两条 assistant 内容完全相同的：**38 对**，分布在 **35 段**（源数据里共 98 对，其中 38 对落在通过 6 条规则的段里）。

## 6. 我没能做到的部分（判据的边界）

**这 6 条是形态判据，只能去掉"看得出是机翻"的那部分，去掉不了"读起来别扭但形态正常"的翻译腔。** 不要把这 6 条全过当成"这段翻译是好的"。

| 缺陷 | 例子 | 6 条规则能否拦住 | 原因 |
|---|---|---|---|
| 词序直搬 | `你看起来像一个非常好和可爱的人` | ❌ 拦不住 | 全是合法汉字，rep3 低、无 ASCII、无乱码 |

| 习语按字面翻 | `are not seeing eye to eye?` → `没有亲眼看到吗?` | ❌ 拦不住 | 语义错误不体现在形态上 |
| 极性译反 | `you are welcome` → `不欢迎你` | ❌ 拦不住 | 形态完全正常 |
| 长句丢内容 | 从句整段丢失 | ❌ 拦不住 | 丢内容后的句子本身通顺且不短 |
| 凭空加内容 | `Good day!` → `日安! 再见!` | ❌ 拦不住 | 形态正常 |
