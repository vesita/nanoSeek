# 人格训练：语料盘点与方案（v1）

> 2026-09-14 主 AI 手测。**起因**：用户要"人格训练"，不要"用户+模型对话训练"。
> **过程说明**：原计划委托两个只读子代理做盘点（【P1 人格语料盘点】【P2 新阶段落地清单】），
> **两轮全部空收尾、零产物**（`git status` 干净），故改为主 AI 自测。所有数字均为本页命令直出。
> **证据强度**：单次实测（命令可复现）；未做多 seed。

---

## 1. 核心结论

1. **人格是数据分布问题，不是标注/超参问题。**
2. **人格/第一人称语料一直存在，但一次梯度都没产生过** —— 它们全部落在 `v3_lang` 与
   `v3_know`，而这两个阶段**从未跑过**（`out/base_v3_lang`、`out/base_v3_know` 都不存在）。
   唯一跑过的 B 段（`v3_dlg`）里**人格源为 0**。
3. **"补跑 A 段"只能救一半**：
   - **有量的人格声音**（知乎答主 27.5M 字、四大名著 3.0M 字）→ 补跑有实质作用。
   - **"身份"**（`identity_dialogue.txt` 全库仅 **588 字**）→ 补跑也等于没训。必须**造数据 + 过采样**。
4. **`我是` 在语料里是个"占位符"**：知乎 4,545 次、lccc 5,219 次，**每次后面接的东西都不同**
   ⇒ 模型学到的是"`我是` 后面可以接任何东西"，这正是 `你叫什么名字？` → `你叫乔丹的，也叫马里兰卡`
   的机制。**身份不是"没训够"，是被"反向训练"了。**
5. 唯一的身份文件 `identity_dialogue.txt` 内容**是反人格的**，主动教"我没有固定名字"（见 §3）。

grep -c '^用户：' "$p"; grep -c '^模型：' "$p"

### 2.1 阶段归属与"跑没跑"

| 阶段 | bin token 数 | 跑过吗 | 里面的人格源 | 占该阶段 |
|---|---:|---|---|---:|
| `v3_lang` | 280,417,976 | ❌ **没跑** | 四大名著 3,016,686 字；`classical_poetry` 2,166,418 字 | 1.08% / 0.77% |
| `v3_know` | 487,755,407 | ❌ **没跑** | `zhihu_kol` 27,533,298；`muice` 208,343；`identity` 588 | **5.64%** / 0.043% / **0.00012%** |
| `v3_dlg` | 114,228,196 | ✅ **跑了（B 段）** | **无** | **0%** |

验证：

```bash
ls -d out/base_v3_lang out/base_v3_know out/base_v3_dlg   # 前两个不存在
python3 -c "print(975510814/2)"   # 487755407  （know bin，uint16）
```

**合计"从未训练过"的人格语料 ≈ 32.9M token**（zhihu 27.53M + 四大名著 3.02M + poetry 2.17M
+ muice 0.21M + identity 0.0006M）—— 按实测 2470 t/s，**全部走 1 epoch 只要 ≈3.7 小时**。

### 2.2 但"有量"≠"有人格"

区分两件事：

- **口吻（voice）**：`zhihu_kol`（27.5M 字）是第一人称长答，**但它是 136,644 个不同答主**
  ⇒ 只能提供"我"字当头的说话方式，**提供不了身份**。当成身份语料用 = 教模型"我的人生每次都不一样"。
- **身份（identity）**：只有 `muice_dialogue.txt`（沐雪，同一角色 3,975 轮、`沐雪`×255 + `沐沐`×397）
  是**单一角色反复出现**。**它是全库唯一一个成型人格，而它只有 208k 字 / 0.043%。**

## 3. 唯一的身份文件是"反人格"的

`data/chinese/clean_v3/identity_dialogue.txt` 全文 35 行，关键三条（`identity_dialogue.txt:4-14`）：

```
用户：你是谁？
模型：我是一个语言模型，可以陪你聊天、理理思路。你喜欢怎么称呼我都可以，或者你想给我起个什么名字？
用户：你有名字吗？
模型：暂时还没有呢，我可以自己想一个，或者你帮我起一个喜欢的名字也行。
用户：你能给自己起个名字吗？
模型：让我想想……如果让我自己选，叫什么好像都挺有意思的。你觉得什么名字适合我？
```

它**主动教模型"我没有名字、我是谁由你决定"** —— 与"人格训练"的目标完全相反。
⇒ 这份文件必须**重写**，不是补跑。（它躺在一个**只有 588 字**的文件里，本来也传不出信号。）

## 4. 标签口径核实（**我的一个怀疑被推翻，记录在此**）

**疑点**：`clean_v3/*.txt` 全部是 `用户：`/`模型：`（实测 `^A：`=`^B：`=0），
而 `eval_dialogue.py` 默认 `--style=ab`（`A：`/`B：`）⇒ 怀疑 B 段评估用错口径。

**源码核实结论：怀疑不成立，`--style=ab` 是对的。**

证据链：

1. `data/chinese/build_stages.py:269-272` 调用 prepare 时**没有** `--pretrain`：
   ```python
   cmd = [sys.executable, PREPARE, '--char-level', '--val-all',
          '--val-ratio', a.val_ratio, '--seed', a.seed,
          '--source-dir', os.path.join(a.stages_dir, stage),
          '--out-prefix', stage, '--emit-offsets']
   ```
2. `data/chinese/prepare.py:191` 的 `annotate_replies(block, ab_rate=0.7, quote_rate=0.8)`
   在**构建 bin 时**把 `用户：/模型：` 转成混合样式，`prepare.py:197`：
   `70% → A：/B： 前缀 (A=对方/用户, B=模型)`。
3. `--pretrain`（"按原始文本编码、不解析 用户：/模型："，`prepare.py:580-581`）**没有被使用**。

⇒ **`用户：`/`模型：` 不进入训练**；bin 里是 ~70% 的 `A：`/`B：` + 其余无标签/引号样式。
⇒ `eval_dialogue.py` 默认 `ab` 与训练一致，B 段评估**没有**口径错误。

**顺带解释 `turns=0.0`**：`analysis/eval_dialogue_B.txt` 显示 `样式=none(给了 ab)`
—— 生成平均只有 22.5 字，**根本没长到下一轮边界**，所以轮次结构必然为空。
这与 `TECH_DEBT` 里"`turns` 是空指标"的记载一致，**不是**格式漂移。

**对人格方案的影响**：B 段学的是**匿名槽位 `B：`（= "我"这个位置）**，不是 `用户/模型` 两个词。
结论方向不变、且更清晰：**把 `B：` 换成角色名（如 `沐雪：`），名字才会进入 token 流成为身份。**

## 5. 建议方案（待用户拍板，尚未动手）

### 5.1 路线

| 路线 | 做法 | 适配 75M | 判断 |
|---|---|---|---|
| **A. 人格即分布** | 语料 = 角色自己的第一人称独白/自述，**无对手方、无角色槽位** | ★★★★★ | **首选**。小模型学得动"一种口吻"，学不动"双角色槽位" |
| **B. 单角色 SFT** | 保留对答，但永远同一角色，标签改**角色名**，身份断言**过采样** | ★★★ | 第二阶段，专治"问名字" |
| **C. 角色 token 条件化** | `<persona:X>` 切多个人格 | ★ | 现在不行，需先有像样基座 |

### 5.2 数据改造四点

1. **拆掉角色槽位**：知乎答主回答**去掉问题、只留第一人称正文**；沐雪记录**去掉"用户"侧、只留沐雪的话**。
   标签由 `B：` 改角色名 `沐雪：`。
2. **人格密度**：现在 0%（B 段）~5.65%（A 段）→ 目标 **10~30%**，其余兑通用语料（控制遗忘，
   B 段已演示过代价：v2-val +0.74）。
3. **身份数据重写 + 过采样 ×100~1000**：一个事实配几十种问法，全部**强断言**。
   手写 200~500 轮即可，成本几十分钟。这是唯一能治"问名字"的手段。
4. **一个阶段只放一个人格**：3975 轮沐雪 + 136,644 个知乎答主**不是同一个人**，混训 = 教"人格是随机的"。

### 5.3 成本

| 方案 | token | 墙钟（2470 t/s） |
|---|---:|---:|
| 现成人格语料 1 epoch | 32.9M | **≈3.7 小时** |
| 混合人格阶段（30% 人格 + 70% 通用） | 150M | ≈17 小时 |
| 同上，更大 | 300M | ≈1.4 天 |

### 5.4 诚实提醒

- **人格 ≠ 知识 ≠ 智能**。人格训练治得好"你叫什么名字"，治不好"1+1"。
- **现有模型已有隐形人格**（共情式心理鸡汤腔）；做人格训练 = **主动选一个声音去放大**。
- 只跑 3 小时的纯人格版会有**遗忘代价**，必须同时报两把尺子（`AGENTS.md §5.12`）。

### 5.5 待用户拍板

1. 角色用途：**纯陪聊角色** vs **要知识的人格助手**（两条路线完全不同）。
2. 人格来源：(a) 选现成的沐雪；(b) 用户自定义人格、由我写成语料；(c) 先立说话方式，再逐步喂知识。
