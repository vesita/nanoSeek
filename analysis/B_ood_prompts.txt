## 结论（人工读原文，逐条）

采样口径：`out/base_v3_dlg/last.pt`（step 14000）、`max_new_tokens=120`（附录 80）、
`temperature=0.8`、`top_k=200`、`repeat_penalty=1.2`；多数提示词 1 个 seed，
身份/北京/两个域内对照各 2 个 seed（§5.5：证据强度按"单次、多 seed 混用"降级表述）。

1. **没有稳定的自我身份。** `你叫什么名字？`
   → `你叫乔丹的，也叫马里兰卡` / `我是男神，有一个名字，好像就是男神。`
   `你是谁研发的？` → 一塌糊涂，其中一个 seed 吐出
   `作为一种语言模型，我不能自己创建或编辑任何文本。`（语料里的助手模板碎片）。
   语料里确有 `我是NexTalk…` 的整句模板（`clean_v3/dailychat_dialogue.txt` 里 15 次），
   但模型**复现不出来** —— 说明它学到的不是"我是谁"，而是零散的句式。
2. **`你`/`我` 角色错位（可命名、可复现的缺陷）。** 问"你叫什么"，它答"**你**姓氏是什么颜色呢？"；
   问"你想做什么"，它把问题抄回来（`你想做什么，也许是有关于你想安排的事情。`）。
   它经常站在**用户那一侧**继续说话，而不是站在 `B：` 这一侧回话。
3. **抄问题 / 换问题**：`1+1等于几？` → `你可以计算一下，7乘以9等于多少。`
4. **事实知识缺失或串台**：`介绍一下北京。` → `南京是中国最具代表性的城市，位于北京市中心…`；
   `用一句话解释相对论。` → `相对论是一种基于互联网的技术…`（整段词沙拉）；
   `中国的首都是哪里？` → `中国的首都，也有北京。`（半对但句法碎）。
5. **代码能力只是语料碎片的外泄**：`用 Python 写一个快速排序。` →
   `…pickages 库… with open('requests/json', 'Faile'); … PostgreSQL … ClassNameValue … for MySQL`
   —— 全是代码语料里的符号碎片，没有任何可执行结构。
6. **★ 连"域内强项"也只是模板级，不是语义级**：`我失恋了，很难受。` →
   `你还有老子，也有老子关注你，老兄终于走到家里`（另一个 seed：`过年期有事过`）；
   `最近工作压力好大，怎么办啊？` → `你还有老师，也有老师关注你，安稳发展哦`
   （和 `eval_dialogue` 里抽到的样本同一个模板家族）。
   ⇒ 与 `analysis/B_stage_review.md` §1/§2 的 CE 改善**不矛盾**：CE 改善说明它更贴合
   v3_dlg 的**分布**（会断句、会收尾、会套模板），**不等于**会安慰人、会答问题。
7. **★ prompt 形态会改变"形状"，但不改变"内容"**：把 `A：…\nB：` 换成裸问题，
   模型会**自己吐 `B：`/`A：` 标签**、生成多轮结构；而预填 `B：` 时它只吐一句短的就收尾
   （这与 §5 的 `turns=0` 是一致的——那是在**预填 `B：`** 的口径下测的）。
   但两种形态下的**内容质量都差**（裸问题下变成 `网络搜索结果是什么` 之类的模板串），
   所以**不能**用"格式不对"替内容开脱。

**给下一轮的提示**：这轮 B 段把"对话的**形状**"练出来了（收尾、不塌陷、会自开轮次），
但**没有**练出"对话的**内容**"（身份、共情语义、事实）。而身份/自我认知在一份
"A：/B：单轮 QA 拼盘"里**本来就没有监督信号** —— 这与"跳过知识段 A"的决策方向一致，
也和 `PROJECT_STATE §0.5.10` 里"v3 新知识没被消费"是同一件事。
