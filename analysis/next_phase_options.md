# 下一阶段选项 —— 把"怎么才能有智慧"变成可选、可判、可估价的方案

**日期**：2026-09-17
**状态**：**决策文档，未执行**。语料一个字节都没动。
**背景**：用户 2026-09-16 问「怎么做，模型才有可能拥有智慧」，这是基于实测证据的回答。
★ 本文所有数字都有出处；`[实测]` 的复现命令在各自来源文档里。

---

## 0. 一句话回答

**在 75M / 单卡 / 这个语料的约束下，"智慧"买不到，只能按能力一项一项买；
而当前卡住我们的不是步数、不是架构，是"目标 × 数据 × 判据"三者还没对齐。**
具体到最要紧的那一维（意图跟随）：**语料对它是"没有监督"，不是"监督不够"。**

可借鉴的方案里，真正适用的只有 **答案段密集监督 + 强教师合成**；
**RL/RLHF 现在做是负收益**（没有可验证的 reward、没有自动判分、75M 的策略太弱）；
KV cache / DSPark / NDB 加速**不解决智慧**（NDB 的 Δ 上界已实测 ≤0.0013 nats）。

## 1. 先看证据：我们现在到底站在哪

### 1.1 意图跟随（"有没有接住对方那句话"）

| 模型 | 判据口径 | 结果 | 可比性 |
|---|---|---|---|
| 站 2 通识（know2） | 14 组 × 2 seed = **28 条** | **0/28** | 基准 |
| 掩码臂（3000 步，masking on） | 同上 28 条 | **4/28**（去回显后；仅 1 条语义也对） | **可直接配对** |
| B 段（14000 步，masking off） | `B_ood_prompts.txt`，**19 条** | **3/19** | ⚠ **不同样本集，不可直接比** |

★ **一个悬着的关键问题**：B 段用了 **8 倍**以上的算力（14000 步 / 114M 有效 token），
而掩码臂只有 3000 步 / ~13M —— **若把 B 段放到同一把尺子上量，两者会不会都是 ~15%？**
如果是，那就说明**不是预算问题，是数据/目标问题**，
那么"把掩码臂延长到 13000 步"这种 13 小时的实验**不值得做**。
⇒ **这是最该先补的一个便宜测量**（见 §3 选项 0）。

### 1.2 自主对话（`eval_multiturn --style ab`）

| 模型 | 收尾率 | **自开轮次率** | 收不住率 |
|---|---:|---:|---:|
| v2 基座（61000） | 100% | 0% | 0% |
| B 段（14000，masking off） | 83% | **17%** | 0% |
| 掩码臂（3000，masking on） | 100% | **0%** | 0% |
| **对照臂（3000，masking off）** | **待跑完** | **待测** | 待测 |

★ 归因**必须等对照臂**：B 段是 14000 步、不是等算力对照。
**待验证假设（[推断]）**：掩码把"提问行"整行排除出 loss，而自开轮次在现语料里
**正是靠提问行提供监督**的 ⇒ 掩码 = 用自开话题换意图跟随。

### 1.3 语料侧的能力供给（`dev-notes/85`）

| 能力 | 语料里的量 | 含义 |
|---|---|---|
| 助手**反问 / 递话头**（推动下一轮） | **18%~38%**（escov 38.0% / glm 26.0% / belle 18.4%） | **充足，可直接学** |
| 助手**显式开启新话题** | **<0.4%** | **几乎为零，要构造** |
| `<topic>` 标记 | **0**（但注入零成本，写进 `.txt` 即单个 id 141） | 需要有人决定"插在哪" |
| 身份污染（自称 OpenAI/ChatGPT） | 最大源里占 **3.4%** 字符 | **真但小**，不是主因 |

### 1.4 每一步的代价（两把尺子，§5.12）

掩码臂（3000 步）实测：**通用尺子 `v3_lang` real 4.7541 → 4.9126（+0.159，7 源全变差）**，
同时 **`v3_dlg` 自身 val −0.297**。⇒ **域内变好是拿通用能力换的**，
且这个"租金"**每一段都要付**（B 段付了 +0.736）。

## 2. 结论：现在该往哪使劲

把三件事分开看，就不会互相甩锅：

| 层 | 现状 | 瓶颈 |
|---|---|---|
| **目标** | "有智慧"不可测 | 必须拆成"接住对方 / 自主对话 / 懂东西"三条**可判分**的行为 |
| **数据** | 意图跟随**没有监督**；显式换话题**没有样本** | **这是主瓶颈** |
| **判据** | `intent_probe` 关键词粗筛，**会放过语义错** | 需要一档内容正确性复核 |
| 算力 | 单卡 8G，3.4 s/it | **不是**当前瓶颈（B 段 8 倍算力没换来能力） |
| 架构 | MoE+MLA+NDB 已就位 | **不是**当前瓶颈 |

**⇒ 该做的是"把能力变成任务、把任务变成数据、把数据变成可判分的验收"，不是加步数。**

## 3. 选项（按「价值 ÷ 代价」排序）

### 选项 0（★ 最便宜，先做）：把 B 段放到同一把尺子上量

- **做什么**：用与掩码臂**完全相同的 28 条**（14 组 × 2 seed）跑 `intent_probe` 评
  `out/base_v3_dlg/last.pt`（B 段终态）。
- **代价**：一次采样，约 15 分钟 GPU。
- **回答什么**：**"8 倍算力到底有没有买到意图跟随？"**
  - 若 B 段也 ≈4/28 ⇒ **预算不是瓶颈**，延长掩码臂（13h）**不值得**，
    直接转"造数据"；这是**省下一整天**的判据。
  - 若 B 段明显更高 ⇒ 预算仍有效，延长是合理选项。
- **风险**：低。唯一注意是**别与训练抢显存**（§5.3），跑完对照臂再做。

### 选项 1（★ 最高价值）：给"意图跟随"造**密集监督**的数据

- **做什么**：构造"指令/问题 → 回答"的**任务型**对话数据，回答段**密集监督**
  （`mask_mode: eos_line` 已能表达，**不需要新代码**），且覆盖 14 组意图对应的言语行为。
- **为什么它是对症的**：现在语料里"接住对方"的信号**被稀释在 80 万个轮次**里，
  且提问行不产生梯度；意图跟随**没有专门的可判分样本**。
- **代价**：数据工作量以"天"计；**不用改模型、不用改架构**。
- **验收**：`intent_probe` 通过率（同 28 条）+ `per_source_ce_probe` 两把尺子 +
  `eval_multiturn` 自开率不恶化。
- **风险**：中期风险是"过拟合到这 28 条"。⇒ 必须**留出**未参与构造的意图组，
  否则 28 条会从判据退化成训练集。

### 选项 2（中等）：构造"助手主动换话题"的多轮数据

- **做什么**：强教师合成多轮对话，**助手段主动开启新话题**，段首插 `<topic>`
  （★ 注入零成本，已实测）。
- **为什么**：这一维在现语料里 **<0.4%**，是**零供给**，加步数长不出来。
- **代价**：中等（要设计话题切换的剧本 + 生成 + 验收）。
- **验收**：`eval_multiturn` 自开轮次率 + 人工读样本（这一维**没有**自动判据，是短板）。

### 选项 3（便宜，防漏）：给每一段加**通用 replay**

- **做什么**：分段训练时按比例混入 `v3_lang`（或 `v3_know`），
  或把 lr 再降一档。
- **为什么**：实测**每段都在付通用能力的租金**（本段 +0.159 / B 段 +0.736）。
- **代价**：改一行配置 + 重跑该段；**不需要新数据**。
- **验收**：`v3_lang` real 的 Δ 应显著小于无 replay 的对照（**必须配对**）。

### 选项 4（现在**不做**，但要写清为什么）

| 方案 | 为什么不做 |
|---|---|
| RL / RLHF / DPO | **没有可验证的 reward**，没有自动判分器，75M 策略太弱 ⇒ 只会加噪声 |
| 加参数 / 换架构 | B 段 8 倍算力没换来意图跟随 ⇒ 瓶颈不在容量（**待选项 0 确认**） |
| KV cache / DSPark / 推理加速 | 解决**延迟**，不解决**智慧** |
| 继续在 v3_dlg 上加步数 | 同上；除非选项 0 显示预算仍有效 |
| 清洗身份污染 | **真但小**（3.4%），**不足以解释意图跟随失败**，性价比低于上面几条 |

## 4. 判据的短板（必须一起修，否则上面都白做）

1. **`intent_probe` 会放过"语义错"**：4 条通过里 3 条是命中关键词但内容胡话。
   ⇒ 加一档**内容正确性**复核（人工 + 模型复核），否则 4/28 与 1/28 被算成同一件事。
2. **"自开轮次率"没有对应的数据判据**：`eval_multiturn` 只量轮次结构，
   量不出"新话题是否真的新"。⇒ 造数据时**同步**定义判据，别等训完再想。
3. **28 条样本太少**：单条翻转就是 3.6 个百分点。
   ⇒ 扩到 60~100 条，并按**留出**划分（见选项 1 的风险）。
